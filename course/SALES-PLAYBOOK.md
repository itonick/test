## 1. 商品の立ち位置

### 競合とその弱点

| 競合 | 価格帯 | 弱点 |
| --- | --- | --- |
| プログラミングスクール | 30〜80万円 | 高額。AI活用の指導が追いついていない |
| Udemy の単発講座 | 2,000〜15,000円 | 断片的。HTML〜Laravel を一気通貫で扱うものが少ない |
| 無料学習サイト | 0円 | 詰まったときの解決策がない。挫折率が高い |
| 技術書 | 3,000円前後 | 環境構築でつまずくと進めない。AI前提でない |

### 本教材の差別化ポイント（3つ）

1. **AI活用が独立した学習項目になっている**
   - 「AIでコードを書く」ではなく「AIの出力を検証する」を教える教材はほぼ存在しない
   - レッスン 0-6 / 0-7 / 1-13 / 2-12 / 3-11 / 4-9 / 5-15 / 6-5 / 6-7 の9本がAI専用回

2. **躓きを構造的に潰している**
   - 全レッスンに「⚠️ つまずきポイント」
   - 独立した**エラー図鑑**（症状からの逆引き）
   - 環境構築で「うまくいかない場合」の分岐を全部書いている

3. **一気通貫で、成果物が5つ残る**
   - LP / ToDoアプリ / 掲示板 / フリマアプリ / オリジナル作品
   - ポートフォリオとしてそのまま提出できる

### キャッチコピー案

- 「AIに書かせるな。AIを疑え。 — 現場で通用する初学者の育て方」
- 「180時間で、AIと一緒に開発できる人になる」
- 「エラーで止まらない。挫折しないWeb開発入門」

## 2. 価格設計

### 推奨：3プラン構成

| プラン | 内容 | 価格 |
| --- | --- | --- |
| **ライト** | 第0部〜第2部（HTML/CSS/JS）+ 巻末資料 | 4,980円 |
| **スタンダード** | 全7部 + 巻末資料 + 完成コード一式 | 14,800円 |
| **サポート付き** | スタンダード + 質問対応（3ヶ月・回数無制限） | 49,800円 |

**価格の根拠**

- スクールの 1/20〜1/50 という比較を明示する
- Udemy 単発（〜15,000円）と同価格帯に「全7部」を置くことで割安感を出す
- サポート付きは、**利益の主軸**にする（教材本体は集客商品）

### 値付けの注意

- **無料公開部分を必ず作る**：第0部（オリエンテーション）は全文無料公開を推奨
  - 環境構築とAI入門は、最も「役立った」と言われやすく、拡散されやすい
  - ここで信頼を作ってから有料部分に誘導する
- 買い切りにする（サブスクは初学者に心理的ハードルが高い）
- 「アップデート無償」を明記する（技術教材の陳腐化への回答）

## 5. 制作の優先順位

全62レッスンを一度に書き切ろうとすると完成しません。**この順で作ります。**

| フェーズ | やること | 目的 |
| --- | --- | --- |
| **Phase 1**（済） | 第0部・巻末資料・LP用サンプル | **無料公開して反応を見る** |
| Phase 2 | 第1部（HTML/CSS）+ 総合演習1 | ライトプランの下地 |
| Phase 3 | 第2部（JavaScript）+ 総合演習2 | ライトプラン完成 → **先行販売開始** |
| Phase 4 | 第3部・第4部（PHP / DB） | スタンダードの中核 |
| Phase 5 | 第5部（Laravel） | 最も工数が重い。ここで差がつく |
| Phase 6 | 第6部（ポートフォリオ・公開） | 完成 |

> 💡 **Phase 3 の時点で先行販売を始める**のを強く推奨します。
> 「完成後に販売」だと、市場の反応を知らないまま100時間以上を投じることになります。
> 先行販売価格（例：スタンダード 9,800円）で買ってもらい、完成に合わせて値上げする形が安全です。

## 7. アップデート運用

技術教材は**放置すると死にます。** 以下を定期的に確認してください。

| 頻度 | 確認項目 |
| --- | --- |
| 3ヶ月ごと | Laravel / PHP のバージョン、XAMPP / MAMP の画面変更 |

> これを繰り返すことで、教材は市販の書籍を超えていきます。
