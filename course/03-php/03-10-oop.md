## 📖 なぜクラスが必要か

ここまでは、**配列と関数**でプログラムを書いてきました。

```php
<?php
$user = ["name" => "太郎", "email" => "a@b.com", "age" => 20];

echo get_display_name($user);
echo is_adult($user);
```

これで動きますが、規模が大きくなると問題が出ます。

| 問題 | 具体的に |
| --- | --- |
| **キー名の間違いに気づけない** | `$user["nmae"]` としても、Warning が出るだけ |
| **どんなキーがあるか不明** | コードを読まないとわからない。IDE も補完できない |
| **不正な状態を作れてしまう** | `$user["age"] = -5;` を誰でもできる |
| **関数がバラバラ** | `user_` で始まる関数が20個並ぶ |

**クラスは、「データ」と「そのデータを扱う処理」をまとめる仕組み**です。

## ✍️ 手を動かす① ─ 最小のクラス

```php
<?php
declare(strict_types=1);

class User
{
    public string $name;
    public string $email;
    public int $age;

    public function __construct(string $name, string $email, int $age)
    {
        $this->name  = $name;
        $this->email = $email;
        $this->age   = $age;
    }

    public function isAdult(): bool
    {
        return $this->age >= 20;
    }

    public function getDisplayName(): string
    {
        return $this->name . "さん";
    }
}

// 使う
$user = new User("山田太郎", "taro@example.com", 20);

echo $user->name;              // 山田太郎
echo $user->getDisplayName();  // 山田太郎さん
var_dump($user->isAdult());    // true
```

### 用語

| 用語 | 意味 |
| --- | --- |
| **クラス** | 設計図 |
| **インスタンス（オブジェクト）** | 設計図から作った実体 |
| **プロパティ** | クラスが持つ変数 |
| **メソッド** | クラスが持つ関数 |
| **コンストラクタ** | `new` したときに自動で呼ばれるメソッド |
| **`$this`** | 「自分自身」を指す |

> ⚠️ **`$this->name` に `$` を付けません。** `$this->$name` は別の意味（可変プロパティ）になります。

### コンストラクタの省略記法（PHP 8以降）

```php
<?php
// 従来の書き方
class User
{
    public string $name;
    public function __construct(string $name) { $this->name = $name; }
}

// PHP 8：コンストラクタプロモーション
class User
{
    public function __construct(
        public string $name,
        public string $email,
        public int $age,
    ) {}
}
```

**プロパティの宣言と代入が、1か所にまとまります。** 実務ではこちらが主流です。

## ✍️ 手を動かす② ─ アクセス修飾子

```php
<?php
class BankAccount
{
    public function __construct(
        public readonly string $owner,     // 読み取り専用（PHP 8.1以降）
        private int $balance = 0,          // 外から触れない
    ) {}

    public function deposit(int $amount): void
    {
        if ($amount <= 0) {
            throw new InvalidArgumentException("入金額は1円以上にしてください");
        }
        $this->balance += $amount;
    }

    public function withdraw(int $amount): void
    {
        if ($amount > $this->balance) {
            throw new RuntimeException("残高が不足しています");
        }
        $this->balance -= $amount;
    }

    public function getBalance(): int
    {
        return $this->balance;
    }
}

$acc = new BankAccount("山田太郎");
$acc->deposit(10000);
echo $acc->getBalance();   // 10000

$acc->balance = 999999;    // ❌ Error: Cannot access private property
$acc->owner = "他人";       // ❌ Error: Cannot modify readonly property
$acc->withdraw(99999);     // ❌ RuntimeException: 残高が不足しています
```

| 修飾子 | 誰がアクセスできるか |
| --- | --- |
| `public` | どこからでも |
| `protected` | 自分と、継承したクラス |
| `private` | **自分だけ** |
| `readonly` | 初期化後は変更不可 |

> 💡 **これが「カプセル化」です。**
> 残高を直接書き換えられないので、**「必ず正しい手続きを通る」ことが保証**されます。
>
> 配列だと `$account["balance"] = 999999;` と書けてしまいます。
> **不正な状態を作れなくする**のが、クラスを使う最大の理由です。

### 基本方針

> **プロパティは `private`。必要なものだけ `public` なメソッドで公開する。**

## ✍️ 手を動かす③ ─ 静的メンバとファクトリ

```php
<?php
class Money
{
    private function __construct(
        private readonly int $amount,   // 円単位の整数（小数を使わない）
    ) {}

    // ---------- ファクトリメソッド ----------
    public static function fromYen(int $yen): self
    {
        if ($yen < 0) {
            throw new InvalidArgumentException("金額は0以上にしてください");
        }
        return new self($yen);
    }

    public static function zero(): self
    {
        return new self(0);
    }

    // ---------- 演算（新しいインスタンスを返す） ----------
    public function add(Money $other): self
    {
        return new self($this->amount + $other->amount);
    }

    public function multiply(int $times): self
    {
        return new self($this->amount * $times);
    }

    public function withTax(float $rate = 0.1): self
    {
        return new self((int) floor($this->amount * (1 + $rate)));
    }

    // ---------- 表示 ----------
    public function toInt(): int
    {
        return $this->amount;
    }

    public function format(): string
    {
        return number_format($this->amount) . "円";
    }
}

// 使う
$price = Money::fromYen(600);
$total = $price->multiply(3)->withTax();

echo $total->format();   // 1,980円
```

| 記法 | 意味 |
| --- | --- |
| `static` | インスタンスを作らずに呼べる |
| `Money::fromYen()` | `::` で静的メソッドを呼ぶ |
| `self` | 自分のクラス |
| `new self(...)` | 自分のインスタンスを作る |

> 💡 **メソッドが `$this` を返さず新しいインスタンスを返す**ことで、
> 「元の値が変わらない」（イミュータブル）設計になっています。
>
> 第2部で学んだ「元の配列を破壊しない」と同じ考え方です。

> 💡 **`private function __construct`** にすると、`new Money(600)` を禁止できます。
> **必ず `Money::fromYen(600)` を通る**ので、検証を確実に実行できます。

## ✍️ 手を動かす④ ─ 継承とインターフェース

### 継承（`extends`）

```php
<?php
abstract class Shape
{
    abstract public function area(): float;      // 中身は子が実装する

    public function describe(): string
    {
        return static::class . " の面積は " . number_format($this->area(), 2);
    }
}

class Rectangle extends Shape
{
    public function __construct(
        private readonly float $width,
        private readonly float $height,
    ) {}

    public function area(): float
    {
        return $this->width * $this->height;
    }
}

class Circle extends Shape
{
    public function __construct(private readonly float $radius) {}

    public function area(): float
    {
        return M_PI * $this->radius ** 2;
    }
}

$shapes = [new Rectangle(3, 4), new Circle(5)];
foreach ($shapes as $shape) {
    echo $shape->describe() . "\n";
}
```

> ⚠️ **継承は便利ですが、使いすぎると保守できなくなります。**
> 「AはBの一種である」という関係のときだけ使ってください。
> 「AはBの機能を使いたい」だけなら、**継承ではなく「持たせる」（コンポジション）**が適切です。

### インターフェース（`implements`）

```php
<?php
interface Formatter
{
    public function format(array $data): string;
}

class JsonFormatter implements Formatter
{
    public function format(array $data): string
    {
        return json_encode($data, JSON_UNESCAPED_UNICODE | JSON_PRETTY_PRINT);
    }
}

class CsvFormatter implements Formatter
{
    public function format(array $data): string
    {
        $lines = [];
        foreach ($data as $row) {
            $lines[] = implode(",", array_map(
                fn($v) => '"' . str_replace('"', '""', (string) $v) . '"',
                $row
            ));
        }
        return implode("\n", $lines);
    }
}

// 受け取る側は「Formatter である」ことしか知らない
function export(array $data, Formatter $formatter): string
{
    return $formatter->format($data);
}

echo export($rows, new JsonFormatter());
echo export($rows, new CsvFormatter());
```

> 💡 **インターフェースは「約束事」です。**
> 「`format()` メソッドを持っている」ことだけを保証します。
>
> **後から `XmlFormatter` を追加しても、`export()` を1行も変えずに使えます。**
> これが「拡張に開かれ、修正に閉じている」という設計原則です。

## ✍️ 手を動かす⑤ ─ 名前空間とオートロード

**第5部（Laravel）を理解するために、必須の知識です。**

### 名前空間（namespace）

クラス名の衝突を防ぐ「住所」です。

```php
<?php
// app/Models/User.php
declare(strict_types=1);

namespace App\Models;

class User
{
    public function __construct(public string $name) {}
}
```

```php
<?php
// app/Services/UserService.php
declare(strict_types=1);

namespace App\Services;

use App\Models\User;          // ← 使うクラスを宣言

class UserService
{
    public function create(string $name): User
    {
        return new User($name);
    }
}
```

```php
<?php
// index.php
declare(strict_types=1);

use App\Services\UserService;

$service = new UserService();
$user = $service->create("太郎");
```

| 記法 | 意味 |
| --- | --- |
| `namespace App\Models;` | このファイルのクラスの住所 |
| `use App\Models\User;` | このクラスを短い名前で使う |
| `\App\Models\User` | 完全修飾名（先頭の `\` でルートから） |

> ⚠️ **`use` は「読み込み」ではありません。** ファイルは読み込まれません。
> **「この名前を、この完全修飾名の別名にする」という宣言**だけです。
> 実際の読み込みは、次のオートロードが行います。

### オートロード（Composer）

**クラスを使った瞬間に、対応するファイルを自動で読み込む仕組み**です。

`composer.json`

```json
{
    "name": "yourname/php-lesson",
    "type": "project",
    "require": {
        "php": ">=8.1"
    },
    "autoload": {
        "psr-4": {
            "App\\": "app/"
        }
    }
}
```

```bash
composer dump-autoload
```

```php
<?php
// index.php
require __DIR__ . "/vendor/autoload.php";   // ← これ1行だけ

use App\Models\User;
$user = new User("太郎");      // ← app/Models/User.php が自動で読み込まれる
```

### PSR-4 のルール

```
名前空間        ディレクトリ
App\           →  app/
App\Models\User → app/Models/User.php
App\Services\UserService → app/Services/UserService.php
```

**「名前空間 = ディレクトリ構造」「クラス名 = ファイル名」** を守れば、自動で読み込まれます。

> ⚠️ **クラス名とファイル名は、大文字小文字も含めて一致させてください。**
> Windows では動いても、Linux（本番サーバー）では動きません。**これは実務で頻発する事故です。**

> 💡 **`require_once` を1つずつ書く時代は終わりました。**
> Laravel（第5部）も、この仕組みの上に成り立っています。

### Composer のインストール

```bash
# インストール確認
composer --version

# プロジェクトの初期化
composer init

# オートロードの生成
composer dump-autoload
```

未インストールなら https://getcomposer.org/ から導入してください。**第5部で必須になります。**

## ✍️ 手を動かす⑥ ─ 実践：投稿クラスを作る

第3部の総合演習（掲示板）で使うクラスを作ります。

`app/Models/Post.php`（📋 完成形は `code/03-10/app/Models/Post.php`）

```php
<?php
declare(strict_types=1);

namespace App\Models;

use InvalidArgumentException;

final class Post
{
    public const MAX_NAME_LENGTH = 30;
    public const MAX_BODY_LENGTH = 1000;

    private function __construct(
        public readonly string $id,
        public readonly string $name,
        public readonly string $body,
        public readonly int    $createdAt,
    ) {}

    /**
     * 新規投稿を作る（検証つき）
     * @throws InvalidArgumentException
     */
    public static function create(string $name, string $body): self
    {
        $name = self::normalize($name);
        $body = self::normalize($body);

        if ($name === "") {
            throw new InvalidArgumentException("お名前を入力してください");
        }
        if (mb_strlen($name) > self::MAX_NAME_LENGTH) {
            throw new InvalidArgumentException(
                sprintf("お名前は%d文字以内で入力してください", self::MAX_NAME_LENGTH)
            );
        }
        if ($body === "") {
            throw new InvalidArgumentException("本文を入力してください");
        }
        if (mb_strlen($body) > self::MAX_BODY_LENGTH) {
            throw new InvalidArgumentException(
                sprintf("本文は%d文字以内で入力してください（現在%d文字）",
                        self::MAX_BODY_LENGTH, mb_strlen($body))
            );
        }

        return new self(
            id:        bin2hex(random_bytes(8)),
            name:      $name,
            body:      $body,
            createdAt: time(),
        );
    }

    /**
     * 保存データから復元する
     */
    public static function fromArray(array $row): self
    {
        return new self(
            id:        (string) ($row["id"] ?? ""),
            name:      (string) ($row["name"] ?? ""),
            body:      (string) ($row["body"] ?? ""),
            createdAt: (int)    ($row["created_at"] ?? 0),
        );
    }

    /**
     * 保存用の配列にする
     */
    public function toArray(): array
    {
        return [
            "id"         => $this->id,
            "name"       => $this->name,
            "body"       => $this->body,
            "created_at" => $this->createdAt,
        ];
    }

    public function formattedDate(): string
    {
        return date("Y年n月j日 H:i", $this->createdAt);
    }

    private static function normalize(string $value): string
    {
        // 全角スペースも含めて trim し、制御文字を除去する
        $value = trim($value, " \t\n\r\0\x0B　");
        return preg_replace('/[\x00-\x08\x0B\x0C\x0E-\x1F\x7F]/u', "", $value) ?? "";
    }
}
```

### この設計のポイント

| 実装 | 理由 |
| --- | --- |
| `final class` | 継承を禁止（意図しない拡張を防ぐ） |
| `private __construct` | **必ず `create()` か `fromArray()` を通る** |
| `readonly` | 作成後は変更不可（不正な状態にならない） |
| `create()` で検証 | **検証を通らないインスタンスが存在できない** |
| `fromArray()` / `toArray()` | 保存形式との変換を1か所に集約 |
| 定数で上限を定義 | マジックナンバーを避ける |
| 名前付き引数 | 引数の意味が読める |

> 💡 **「不正なインスタンスを作れない」ようにするのが、クラス設計の核心です。**
>
> 配列だと `["name" => "", "body" => ""]` を作れてしまいますが、
> `Post::create("", "")` は**例外を投げて止まります**。

### リポジトリクラス（保存を担当）

`app/Repositories/PostRepository.php`

```php
<?php
declare(strict_types=1);

namespace App\Repositories;

use App\Models\Post;
use RuntimeException;

final class PostRepository
{
    public function __construct(private readonly string $filePath) {}

    /** @return Post[] 新しい順 */
    public function all(): array
    {
        $rows = $this->load();
        $posts = array_map(fn(array $r) => Post::fromArray($r), $rows);
        usort($posts, fn(Post $a, Post $b) => $b->createdAt <=> $a->createdAt);
        return $posts;
    }

    public function find(string $id): ?Post
    {
        foreach ($this->all() as $post) {
            if ($post->id === $id) return $post;
        }
        return null;
    }

    public function save(Post $post): void
    {
        $rows = $this->load();
        $rows[] = $post->toArray();
        $this->store($rows);
    }

    public function delete(string $id): bool
    {
        $rows = $this->load();
        $filtered = array_values(array_filter($rows, fn($r) => ($r["id"] ?? "") !== $id));

        if (count($filtered) === count($rows)) {
            return false;   // 見つからなかった
        }

        $this->store($filtered);
        return true;
    }

    // ---------- 内部 ----------

    private function load(): array
    {
        if (!is_file($this->filePath)) return [];

        $raw = file_get_contents($this->filePath);
        if ($raw === false || $raw === "") return [];

        $data = json_decode($raw, true);
        return is_array($data) ? $data : [];
    }

    private function store(array $rows): void
    {
        $dir = dirname($this->filePath);
        if (!is_dir($dir) && !mkdir($dir, 0755, true) && !is_dir($dir)) {
            throw new RuntimeException("保存先を作成できません: {$dir}");
        }

        $json = json_encode($rows, JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE | JSON_UNESCAPED_SLASHES);
        if ($json === false) {
            throw new RuntimeException("JSONへの変換に失敗しました");
        }

        if (file_put_contents($this->filePath, $json, LOCK_EX) === false) {
            throw new RuntimeException("ファイルの保存に失敗しました");
        }
    }
}
```

> 💡 **「データの保存先を、1つのクラスに閉じ込める」**のがリポジトリパターンです。
>
> 第4部でデータベースに移行するとき、**`PostRepository` の中身だけを書き換えれば済みます**。
> 呼び出し側（`index.php`）は1行も変わりません。**これが設計の力です。**

## ⚠️ つまずきポイントまとめ

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| `Cannot access private property` | private に外からアクセスした | ゲッターを作るか、public にする |
| `$this` が使えない | 静的メソッド内で使った | `self::` を使う |
| `$this->$name` で変な動き | `$` を余分に付けた | `$this->name` |
| `Class not found` | オートロード設定 / 名前空間とパスの不一致 | `composer dump-autoload`、大文字小文字を確認 |
| `use` したのに読み込まれない | `use` は別名宣言だけ | `require vendor/autoload.php` |
| Linux で動かない | ファイル名の大文字小文字 | クラス名と完全一致させる |
| `readonly` で代入エラー | 初期化後は変更不可 | 新しいインスタンスを作る |

### 演習2（必須）─ 配列版をクラスに書き換える

以下の配列ベースのコードを、クラスに書き換えてください。

```php
<?php
$cart = [];

function add_to_cart(array $cart, string $id, int $price, int $qty): array {
    $cart[] = ["id" => $id, "price" => $price, "qty" => $qty];
    return $cart;
}

function cart_total(array $cart): int {
    $sum = 0;
    foreach ($cart as $item) {
        $sum += $item["price"] * $item["qty"];
    }
    return $sum;
}

function cart_count(array $cart): int {
    $n = 0;
    foreach ($cart as $item) { $n += $item["qty"]; }
    return $n;
}
```
