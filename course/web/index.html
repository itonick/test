01

なぜ挫折するのか

プログラミング学習が続かない理由は、才能でも意志でもありません。原因は驚くほど決まっていて、 そのすべてが教材の設計で潰せます。この教材は、この4つを潰すためだけに構成されています。

CAUSE 01

環境構築で詰む

「書いてある通りにやったのに動かない」。OSも既存ソフトも人によって違うのだから当然です。うまくいかなかったときの分岐まで全部書きます。ポート衝突の犯人3種、その特定手順まで。

CAUSE 02

エラーが読めず止まる

英語のエラーは、3か所だけ拾えば読めます。全レッスンに「つまずきポイント」を置き、巻末には症状から逆引きできるエラー図鑑を用意しました。

CAUSE 03

写経しても身につかない

読む → 打つ → AIに説明させる → 自分で変える。この4ステップを毎回踏みます。3番目が理解の穴を可視化し、4番目が応用力になります。

CAUSE 04

AIに丸投げして詰む

動くコードは手に入っても、実力は残りません。AI活用を独立した学習項目として扱い、聞き方・検証の仕方・任せてはいけない範囲まで教えます。

03

サンプルレッスン

第0部の最終レッスンを、実際の形式のまま掲載します。全62レッスンがこの構成です。

LESSON 0-7 ／ 60分 ／ 難度 ふつう

AIの答えを疑う技術 — 検証編

このレッスンのゴール
  • AIの回答が信用できるかを、初学者でも判定できるようになる
  • 5段階の検証手順を身につける
  • AIに任せてはいけない領域を線引きできる

この技術が、あなたの市場価値になる

いま「AIにコードを書かせられる人」は珍しくありません。誰でもできます。希少なのは、AIが出したコードの正しさを判断できる人です。

現場では、AIが出したコードをそのまま入れてSQLインジェクションの穴が空いた、提案されたライブラリが3年前に開発終了していた、といった事故が実際に起きています。これらをリリース前に止められる人が、いま最も評価されています。

AIが間違える5つのパターン

パターン具体例見抜き方
存在しないものを作るPHPに str_reverse() はない（正しくは strrev()）公式ドキュメントで検索する
情報が古いPHP 7.0 で削除された mysql_query() を提示する「非推奨になっていませんか」と追加で聞く
バージョンがずれるLaravel 11 の質問に 8 の書き方で答える質問時に必ずバージョンを書く
質問を誤解するズレた問いに、完成度の高い答えを返す「私の質問をどう理解したか要約して」
動くが、まずいSQLインジェクションやXSSを含んだまま動作する別会話でセキュリティレビューをかける
⚠ つまずきポイント

5番目が最も危険です。動いてしまうので、初学者には問題が見えません。「動いた＝正しい」は、この教材で最初に捨てる思い込みです。

検証の5ステップ

  1. 自分の言葉で説明できるか？できないコードは使わない。「この行がないとどうなりますか」と聞き返す。
  2. その関数は実在するか？php.net / MDN で検索する。ページが無ければ、その関数は存在しない。
  3. 動かして、期待通りか？正常系だけでなく、空・特殊文字・0・極端に長い入力も試す。
  4. セキュリティ上の問題はないか？新しい会話でレビューさせる。同じ会話だと自分の出力を庇う傾向がある。
  5. もっと簡単な方法はないか？AIは複雑な解を出しがち。「もっと簡単に」と聞き返す。
🤖 AIに聞いてみよう ─ セキュリティレビュー

自分で書いたコードにも、AIに書かせたコードにも、必ずこれをかけます。

以下のコードを、セキュリティの観点からレビューしてください。
Webアプリケーションで、一般ユーザーからの入力を扱うコードです。

（コードを貼る）

次の観点で、問題があれば具体的に指摘してください。
- SQLインジェクション  - XSS  - CSRF
- ファイルアップロードの脆弱性
- 認証・認可の不備   - 機密情報のハードコーディング

それぞれ、なぜ危険か・攻撃されると何が起きるかも説明してください。
問題がない場合は「問題なし」と明言してください。

任せてよい領域 / いけない領域

判断領域
任せてよい概念の説明、エラー文の翻訳、定型コードの雛形、命名のアイデア、自分のコードのレビュー、練習問題の作成
検証すれば可実装コード、SQL文、正規表現、ライブラリ選定、パフォーマンス改善の提案
任せてはいけない「何を作るか」の意思決定、セキュリティの最終判断、個人情報・APIキー・パスワードを含むコードの貼り付け、業務データの投入

やってみよう ─ AIの嘘を見つける

AIに頼らず、自力でやってください。ここが実力になる部分です。

PHPで、文字列を逆順にする関数を教えてください。
また、配列の要素をランダムに並べ替える関数も教えてください。
それぞれ、コード例も示してください。

返ってきた関数名を、すべて php.net で確認してください。正しく答えた場合も、引数の順番と戻り値まで公式で確認します。AIは名前は合っていても引数の順番を間違えることがあります。

⚠ 追加演習 ─ この4行には脆弱性が2つある 
$name = $_GET['name'];
$conn = new mysqli("localhost", "root", "", "testdb");
$result = $conn->query("SELECT * FROM users WHERE name = '$name'");
echo "こんにちは、" . $name . "さん";

上のプロンプトでAIにレビューさせてください。SQLインジェクションとXSSの両方を指摘できましたか？ 指摘できなかったAIの答えは、鵜呑みにできないということです。
