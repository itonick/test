# 販売ガイド ── Udemy / ココナラ で売るための手引き

この教材（全7部・全83レッスン・完成コード付き）を、**Udemy** と **ココナラ** で販売するための素材と手順を、この `sell/` フォルダにまとめています。

---

## まず結論：それぞれ何を売るか

| | Udemy | ココナラ |
| --- | --- | --- |
| 売り物の中心 | **動画講座**（必須。テキストのみは出品不可） | **デジタルデータ**（PDF / HTML / ZIP のダウンロード納品）や、学習サポート |
| この教材の使い方 | 各レッスンを**動画で解説**し、本文・コードを「ダウンロード資料」に添付 | 教材一式（オフラインHTML / PDF / ZIP）を**そのまま納品** |
| 必要な追加作業 | 動画の**収録・編集**（あなたの作業） | ほぼ不要（本フォルダの成果物で出品可能） |
| すぐ売れるのは | ✕（収録が必要） | ◎（今日から出品可能） |

> ⚠️ **正直な注意**：Udemyは「テキスト教材だけ」では公開審査を通りません。**最低30分以上の動画**などの要件があります（要件はUdemy公式の最新情報を確認してください）。本フォルダの `udemy/` は、その動画を撮るための**台本・構成・紹介文**です。動画の収録・編集はあなたの作業になります。

## 納品ファイルの作り方

### ① オフライン教材（HTML・そのまま配れる）
`web/dist/course-offline.html` は、**1ファイルだけで全レッスンが読める**ビューアです。
インターネット接続も、他のファイルも不要。購入者はダブルクリックしてブラウザで開くだけです。
→ ココナラのZIP納品や、Udemyの「ダウンロード資料」に最適。

### ② PDF（ココナラでPDF販売したいとき）
PDFは、`web/dist/course-print.html` を**ブラウザで開き、印刷 → PDFで保存**すれば作れます。

1. `course-print.html` をダブルクリックして Chrome / Edge で開く
2. `Ctrl + P`（Mac は `⌘ + P`）→ 送信先を「**PDFに保存**」
3. 余白「既定」、背景のグラフィック「**ON**」で保存

> 💡 なぜ手作業かというと、制作環境ではPDF変換エンジンが動かなかったためです。ブラウザからの保存が、いちばんきれいで確実です（目次・表・コード枠も再現されます）。

### ③ ZIP一式（コードもまとめて渡すとき）
配布用に、次をまとめて zip 圧縮してください（フォルダごと選択 → 圧縮）。

- `course-offline.html`（①）と、必要なら PDF（②）
- `00-orientation/` 〜 `06-portfolio/` の各Markdown（本文）
- `appendix/`（巻末資料）
- `code/`（完成コード）
- `LICENSE.md`（利用条件）

## 出品までの最短ルート

**ココナラ（今日から）**
1. `course-offline.html` を用意（必要ならPDFも）→ ZIP化
2. `coconala/出品ページ文案.md` の文面をコピペして出品登録
3. 料金プラン（松竹梅）を設定して公開

**Udemy（収録が必要）**
1. `udemy/カリキュラム構成.md` の通りにセクション/レクチャーを登録
2. `udemy/講義台本サンプル.md` を参考に動画を収録・編集
3. 本文・コードを各レクチャーの「ダウンロード資料」に添付
4. `udemy/紹介ページ文案.md` でランディングページを作成 → 審査に提出
