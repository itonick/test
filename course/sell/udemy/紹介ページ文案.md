## コースタイトル（案）

- **AIと一緒につくる Webアプリ開発入門 ── パソコン未経験からLaravelまで**
- （別案）**AIに頼りきらないWeb開発 ── HTML/CSSからLaravel・実務力まで一気通貫**
- （別案）**未経験から作れる人へ：AI時代のWebアプリ開発フルコース（PHP/Laravel）**

> タイトルは検索されるキーワード（未経験・Laravel・PHP・AI・Webアプリ）を含めると見つかりやすくなります。

## サブタイトル（案）

パソコンの基本操作から、HTML/CSS・JavaScript・PHP・MySQL・Laravel、そして「AIの使いこなし」と「自分で考える力」まで。動くアプリを5本、自分の手で作りきる全83レッスン。

---

## このコースで学べること（「学習内容」欄・4つ以上必須）

- HTML / CSS でレスポンシブなWebページをゼロからつくれるようになる
- JavaScript で動きのあるUI（モーダル・タブ・フォーム検証）を実装できる
- PHP と MySQL で、フォーム・ログイン・掲示板などの動的サイトを作れる
- Laravel で「認証つきCRUDアプリ（フリマ）」を一人で作りきれる
- SQLインジェクション・XSS・CSRF など、実務で必須のセキュリティ対策を理解する
- AIに的確に質問し、返ってきたコードの正しさを**自分で検証**できる
- 「何を・なぜ作るか（仕様）」を決め、クリティカルシンキングで判断できる
- 制作物をGitHubに公開し、ポートフォリオとして提示できる

## 要件（受講の前提）

- パソコン（Windows / Mac どちらでも可）とインターネット環境
- プログラミングの事前知識は不要（**パソコンの基本操作から解説します**）
- 有料ソフトは不要（すべて無料ツールで進めます）

## このコースの対象受講者

- プログラミング完全未経験〜少しかじって挫折した人
- 独学が続かなかった人（本コースは「つまずき」を先回りして潰します）
- ChatGPT / Claude を「なんとなく」使っていて、開発で活かしたい人
- 転職・副業・社内DXのために「動くものを1人で作りきる力」が欲しい人

## コース説明文（「説明」欄・長文）

**「動いた＝正しい」で終わらせない。AIの時代に、本当に作れる人になる。**

このコースは、プログラミング未経験の方が、パソコンの基本操作から始めて、最終的に **Laravelで認証つきのWebアプリ（フリマアプリ）を一人で作りきる**までを、一本道で学べる教材です。

多くの入門講座と違うのは、**AIの使い方を「独立した技術」として教える**点です。いまや現役エンジニアのほとんどがAIを使っています。しかし、AIは平気で間違えます。存在しない関数を提案し、脆弱性のあるコードを「動くから」と返してきます。

そこで本コースは、コードの書き方と同時に、**「AIの答えを疑い、検証し、使いこなす技術」**を徹底的に鍛えます。さらに、AIに任せてはいけない人間の仕事──**「何を・なぜ作るかを決める仕様の力」と「クリティカルシンキング」**まで扱います。これらは、技術が変わっても通用する一生モノの力です。

**挫折させないための設計**
- 全レッスンに「つまずきポイント」と「詰まったときのAIへの聞き方」を用意
- 環境構築は Windows / Mac 別に、うまくいかないときの分岐まで解説
- 巻末に「エラー図鑑（症状→原因→直し方）」

**手を動かして残る成果物（5本）**
1. 架空カフェのランディングページ（HTML/CSS）
2. ToDoアプリ（JavaScript）
3. 掲示板アプリ（PHP + MySQL）
4. フリマアプリ（Laravel・認証つき）
5. あなたのオリジナル制作物

学び終えたあとの**キャリアの築き方**（誇張なしの現実的な順番）まで解説します。

さあ、AIを相棒に、「自分で作れる人」になりましょう。

> ⚠️ 効果には個人差があります。習得スピードや成果を保証するものではありません。本コースは「近道」ではなく、「続けられる設計」で着実な前進を支えます。
