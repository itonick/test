# 動画スライドの使い方（録画 → MP4）

このフォルダのスライドは、**あなたが開いて録画するだけ**でUdemy講義動画になるよう作ってあります。

## 入っているもの

| ファイル | 用途 | 尺の目安 |
| --- | --- | --- |
| `プロモ動画.pptx` | コース紹介（プロモーション動画） | 約2分 |
| `レッスン0-1_ようこそ.pptx` | 講義動画のサンプル1本（第0部 0-1） | 約8分 |

**ナレーション台本は、各スライドの「ノート」に全文入っています。** 読み上げるだけでOKです。
（PowerPointの「表示 → ノート」、または発表者ツールで見られます）

配色・フォント（テーマ）
- メインカラー：ティール `#0F766E` ／ 濃い背景 `#12332F` ／ アクセント `#2FBBA6`
- フォント：`Meiryo`（Windows標準。Macは自動代替、または「ヒラギノ角ゴ」に置換推奨）

## いちばん簡単な「動画化」：PowerPointだけでMP4に

PowerPoint（Microsoft 365 / 2019以降）なら、追加ソフトなしでMP4を書き出せます。

1. スライドを開く →「**スライド ショー**」タブ →「**録画**」（またはスライドショーの記録）
2. 各スライドで、**ノートの台本を読み上げながら**録音。マイクは内蔵でも可（できれば外付け推奨）
3. 全スライドを録り終えたら「**ファイル → エクスポート → ビデオの作成**」
4. 画質「**フルHD (1080p)**」を選び、`.mp4` で保存 → **完成**

> 発表者ツールを別画面に出すと、ノート（台本）を見ながら録画できます。1枚ずつ録り直せるので、失敗しても大丈夫です。

## 別の方法：画面収録ソフトで撮る

OBS Studio（無料）／ Zoomの画面共有録画 ／ Macの画面収録（⌘+Shift+5）でも可。
スライドショーを**全画面**にして、ノートの台本を読みながら画面を録画 → 保存。

---

## 収録のコツ

- 画面は 1920×1080、フルスクリーンで
- 台本は棒読みしない。**箇条書きのメモ**として見て、自分の言葉で
- ミスしたら、そのスライドだけ録り直して大丈夫（PowerPointの録画はスライド単位）
- 冒頭10秒で「このレッスンで何ができるようになるか」を必ず言う（離脱を防ぐ）

## 残りのレッスンを量産する

この2本を**テンプレート**にして増やせます。

1. `レッスン0-1_ようこそ.pptx` を複製し、ファイル名を変更
2. 各スライドの文言を、対象レッスンの本文（`レッスン本文/` の Markdown）に差し替え
3. ノートの台本は、`../講義台本サンプル.md` の「1レクチャーの基本の型」に沿って書き直す
4. 配色・フォント・レイアウトはそのまま流用（統一感が出ます）

> プログラムで一括生成したい場合は、このフォルダの `build_promo.js` / `build_lesson01.js`
> （pptxgenjs製）を雛形として、レッスンごとにテキストを差し替えると効率的です。

## Udemyへの載せ方（復習）

- 各レッスンの動画を、`../カリキュラム構成.md` のセクション/レクチャー対応表の通りに配置
- 各レクチャーの「リソース」に、対応する本文Markdownと完成コードを添付
- プロモ動画は「コースの概要（プロモーションビデオ）」に設定
- プレビュー公開の推奨は 0-1 / 0-7 / 1-1（`../カリキュラム構成.md` 参照）
