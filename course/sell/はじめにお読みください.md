# はじめにお読みください ── 教材の使い方

このたびは教材をご購入いただき、ありがとうございます。
**AIと一緒につくる Webアプリ開発入門**（全7部・全83レッスン・完成コード付き）です。

---

## 1. まずはこれを開いてください

同梱の **`教材ビューア_オフライン.html`** をダブルクリックしてください。
お使いのWebブラウザ（Chrome / Edge / Safari など）で開き、**インターネット接続なしで全83レッスンを読めます**。

- 左の「カリキュラム」で部を開き、**レッスン名をクリック**すると本文が開きます
- 進捗チェック、前後移動、コードのコピー、ダーク/ライト切替に対応しています
- チェックの記録は、その端末のブラウザにのみ保存されます（外部送信なし）

## 2. 紙・タブレットで読みたい／PDFが欲しいとき

同梱の **`印刷用_全レッスン.html`** を開き、
**印刷（Windows: `Ctrl + P` / Mac: `⌘ + P`）→ 送信先「PDFに保存」** を選ぶと、
全レッスンを1冊のPDFにできます（余白「既定」、背景のグラフィック「ON」推奨）。

## 3. フォルダの中身

| 名前 | 中身 |
| --- | --- |
| `教材ビューア_オフライン.html` | ネット不要・単一ファイルの教材ビューア（まずこれ） |
| `印刷用_全レッスン.html` | 全レッスンを1冊にまとめた印刷/PDF用 |
| `レッスン本文/` | 各レッスンのMarkdown原文（テキストで読みたい方向け） |
| `完成コード/` | 各レッスンの完成コード（動作確認済み） |
| `LICENSE.md` | 利用条件 |

## 4. 学習の進め方（大切な約束）

1. **コードは手で打つ**（コピペしない）── タイポの直し方が身につきます
2. **15分ルール**── 詰まったら15分粘り、超えたら教材の「つまずきポイント」→「エラー図鑑」→AIの順で助けを借りる
3. **理解度7割で次へ**── 完璧を目指さない。知識は後の章で何度も再登場します

各レッスンの「🤖 AIに聞いてみよう」のプロンプトは、そのままコピペで使えます。

## 5. 必要なもの（すべて無料）

パソコン（Windows / Mac）、インターネット環境、Google Chrome、VS Code、XAMPP または MAMP、無料のAIチャット（ChatGPT / Claude / Gemini のいずれか）。導入手順は第0部で解説しています。
