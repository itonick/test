## ✍️ Day 2 ─ 共通スタイル・ヘッダー・フッター

### 順番が大事

CSSは**「共通 → 個別」の順**で書きます。逆にすると、共通が個別を上書きしてしまいます。

```
1. リセット
2. デザイントークン（:root のカスタムプロパティ）
3. ベース（body, h1〜h3, p, a）
4. レイアウト共通（コンテナ幅、セクション余白）
5. 個別パーツ（ヘッダー、ヒーロー、メニュー…）
6. ユーティリティ（.btn など）
```

### デザイントークンを先に決める

**色とサイズを先に決めてから、パーツを作ります。** これを飛ばすと、後で色がバラバラになります。

```css
:root {
  /* 色 */
  --color-bg:          hsl(35 33% 98%);
  --color-surface:     hsl(0 0% 100%);
  --color-text:        hsl(25 12% 15%);
  --color-text-light:  hsl(25 8%  42%);
  --color-accent:      hsl(25 40% 39%);
  --color-border:      hsl(30 20% 88%);

  /* フォント */
  --font-base: "Noto Sans JP", "Hiragino Sans", system-ui, sans-serif;
  --font-en:   "Marcellus", "Times New Roman", serif;

  /* 文字サイズ */
  --fs-xs:  12px;
  --fs-sm:  14px;
  --fs-base:16px;
  --fs-lg:  clamp(17px, 1.6vw, 19px);
  --fs-2xl: clamp(24px, 3.2vw, 34px);
  --fs-3xl: clamp(28px, 5.2vw, 48px);

  /* レイアウト */
  --container: 1040px;
  --gutter: clamp(16px, 4vw, 32px);
  --section-space: clamp(48px, 8vw, 88px);
  --header-h: 64px;

  /* 重なり順 */
  --z-header: 500;
  --z-float: 400;
}
```

> 💡 **色は自分で変えて構いません。** カフェの雰囲気を変えたければ、`hsl` の色相（最初の数字）を変えてください。
> `hsl(200 40% 39%)` にすれば青系のカフェになります。**変数のおかげで、1行変えるだけで全体が変わります。**

### ヘッダーは2重構造で

```css
/* 外枠：画面幅いっぱい・追従・背景 */
.site-header {
  position: sticky;
  top: 0;
  z-index: var(--z-header);
  background-color: var(--color-bg);
  border-bottom: 1px solid var(--color-border);
}

/* 内枠：幅を制限して中央寄せ */
.header-inner {
  max-width: var(--container);
  margin-inline: auto;
  padding-inline: var(--gutter);
  padding-block: 12px;
  display: flex;
  flex-direction: column;
  align-items: center;
  gap: 6px;
}

@media (min-width: 768px) {
  .header-inner {
    flex-direction: row;
    justify-content: space-between;
    padding-block: 16px;
  }
}
```

**Day 2 のチェック**
- [ ] スクロールしてもヘッダーが追従する
- [ ] ヘッダーの背景が透けていない
- [ ] 768px 未満で縦積み、以上で横並びになる
- [ ] フッターにブランド情報とナビがある

## ✍️ Day 3 ─ ヒーロー・メニュー

### ヒーロー（写真に文字を重ねる）

**必須のポイント**

| 要素 | 理由 |
| --- | --- |
| 親に `position: relative` | absolute の基準を作る |
| `::after` + `inset: 0` + グラデーション | 文字の可読性を確保 |
| 文字に `z-index: 1` | 暗いレイヤーより手前に |
| `aspect-ratio` の切り替え | スマホ縦長 / PC横長 |

> ⚠️ **暗くするレイヤーを必ず入れてください。** 明るい写真だと白文字が全く読めません。
> 開発者ツールの Accessibility タブで、コントラスト比を確認してください。

### メニュー（auto-fit のグリッド）

```css
.menu-list {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(min(100%, 240px), 1fr));
  gap: clamp(28px, 4vw, 40px) clamp(20px, 3vw, 32px);
  margin-top: 40px;
}

.menu-thumb {
  position: relative;
  overflow: hidden;        /* ← ホバー拡大のはみ出しを切る */
  margin-bottom: 16px;
}

.menu-thumb img {
  width: 100%;
  aspect-ratio: 1 / 1;
  object-fit: cover;
  transition: transform .4s ease;
}

.menu-item:hover .menu-thumb img {
  transform: scale(1.05);
}
```

**Day 3 のチェック**
- [ ] ヒーローの文字が写真の上で読める
- [ ] 幅を変えると、メニューが 1列 → 2列 → 3列 と変わる

- [ ] ホバーで画像が拡大し、**はみ出さない**
- [ ] バッジが画像の左上に正しく出る

## ✍️ Day 5 ─ レスポンシブ調整と仕上げ

### 幅ごとの確認

開発者ツールのデバイスモードで、**幅をゆっくりドラッグ**しながら確認してください。

| 幅 | 確認内容 |
| --- | --- |
| **320px** | 横スクロールが出ないか。文字が詰まりすぎていないか |
| 375px | 標準的なスマホでの見え方 |
| 600px | 中間サイズで崩れないか |
| 768px | タブレット。ヘッダーが横並びに切り替わるか |
| 1024px | メニューが3列になっているか |
| 1440px | 余白がスカスカでないか。`max-width` が効いているか |

### 横スクロールの最終チェック

Console に貼って実行してください（📋 コピペ可）。

```javascript
document.querySelectorAll('*').forEach(el => {
  if (el.getBoundingClientRect().right > document.documentElement.clientWidth + 1) {
    console.log('はみ出し:', el);
  }
});
```

**何も出力されなければ合格です。**

## 🔧 発展課題（余力があれば）

### 課題A：自分の店に作り替える

架空のカフェではなく、**自分が作りたいテーマ**でLPを1枚作ってください。

| テーマの例 | 変えるところ |
| --- | --- |
| 美容室 | メニュー → 施術メニュー、写真 → スタイル写真 |
| 個人の書店 | メニュー → おすすめの本、ABOUT → 店主の話 |
| ヨガスタジオ | メニュー → クラス紹介、ACCESS → 予約導線 |
| 自分のポートフォリオ | メニュー → 制作物、ABOUT → 経歴 |

**HTMLとCSSの構造はそのまま流用できます。** 中身と色を変えるだけです。
`hsl` の色相を変えるだけで、まったく違う印象になることを体験してください。

### 課題B：2ページ目を作る

- [ ] `pages/menu.html` を作り、メニュー詳細ページにする
- [ ] ヘッダーとフッターを、トップページと同じ見た目にする
- [ ] トップページから相互にリンクを張る（**相対パスに注意**）
- [ ] CSSは1つのファイルを共有する

> 💡 ヘッダーとフッターのHTMLをコピペすることになりますが、それで構いません。
> **「同じHTMLを何度も書くのは無駄だ」という感覚が、第3部（PHP の `include`）への動機になります。**

### 課題C：GitHubに公開する

第6部（6-1）を先取りして、GitHub Pages で公開してみてください。

1. GitHub でアカウントを作る
2. リポジトリを作る
3. ファイルをアップロード
4. Settings → Pages → Branch を `main` にして Save
5. 数分後、`https://ユーザー名.github.io/リポジトリ名/` で公開される

**世界に公開されたURLを持つことは、大きなモチベーションになります。**
