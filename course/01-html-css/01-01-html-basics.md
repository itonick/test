## 📖 HTMLは「見た目」を書く言語ではない

初学者が最初に持つ、最大の誤解がこれです。

> ❌ 「`<h1>` は文字を大きくするタグ」
> ✅ 「`<h1>` は**このページの最も重要な見出し**であることを示すタグ」

結果として文字が大きくなりますが、それは**ブラウザがそう表示しているだけ**です。CSSを書けば、`<h1>` を小さくすることもできます。

### では、なぜ「意味」を書くのか

意味を正しく書くと、3つの人（もの）が幸せになります。

| 誰が | どう嬉しいか |
| --- | --- |
| **検索エンジン** | ページの構造を理解でき、検索結果に正しく出る（SEO） |
| **スクリーンリーダー** | 目の見えない人が「見出しだけ拾い読み」できる |
| **未来の自分・チーム** | コードを読んだだけで構造がわかる |

> 💡 「文字を大きくしたいから `<h1>`」で書かれたページは、見出しが10個並んだ意味不明な構造になります。**装飾はCSSに任せ、HTMLは意味だけを書く**。これがHTMLの大原則です。

## ✍️ 手を動かす① ─ タグの形を覚える

### タグ・要素・属性

```html
<a href="https://example.com">サンプルサイト</a>
│└┬┘ └────┬───────────────┘ └────┬─────┘ └┬─┘
│ │        │                     │        └── 終了タグ
│ │        └── 属性              └── 内容
│ └── タグ名
└── 開始タグ

└──────────── ここ全体が「a要素」 ────────────┘
```

| 用語 | 意味 |
| --- | --- |
| **タグ** | `<a>` `</a>` のような記号 |
| **要素** | 開始タグから終了タグまでの一かたまり |
| **属性** | タグに追加する情報。`属性名="値"` の形 |
| **内容** | 開始タグと終了タグに挟まれた部分 |

### 終了タグがないタグもある

```html
<img src="cat.png" alt="猫の写真">
<br>
<hr>
<meta charset="UTF-8">
```

これらは**空要素**と呼ばれ、内容を持たないので終了タグがありません。

> ⚠️ **つまずきポイント：終了タグの閉じ忘れ**
> HTMLは、閉じ忘れてもエラーを出しません。**黙ってレイアウトが崩れます。**
> これが初学者にとって最も厄介です。対策は次の2つ。
> 1. **開始タグを書いたら、先に終了タグを書く**（内容は後から埋める）
> 2. Emmet（`p` + `Tab`）を使う。自動で両方書かれる

### 入れ子（ネスト）のルール

タグは入れ子にできますが、**順番を守る**必要があります。

```html
<!-- ✅ 正しい：内側から順に閉じる -->
<p>これは<strong>重要</strong>です</p>

<!-- ❌ 間違い：交差している -->
<p>これは<strong>重要</p></strong>
```

**インデント（字下げ）で入れ子を表現**すると、間違いに気づきやすくなります。

```html
<ul>
  <li>項目1</li>
  <li>項目2</li>
</ul>
```

## ✍️ 手を動かす② ─ 最小のHTMLファイル

### ファイルを作る

1. `htdocs/lesson` の中に `01-01` フォルダを作る
2. VS Code でそのフォルダを開く
3. `index.html` を新規作成
4. `!` と打って `Tab` キー（Emmet）

出てきた雛形を、以下のように直します。**手で打ってください。**

```html
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>山田太郎のプロフィール</title>
</head>
<body>
  <h1>山田 太郎</h1>
</body>
</html>
```

### 雛形の各行の意味

読み飛ばさないでください。**ここを理解しておくと、後で文字化けやスマホ崩れの原因が自分でわかります。**

| 行 | 意味 | 書かないとどうなるか |
| --- | --- | --- |
| `<!DOCTYPE html>` | 「これはHTML5の文書です」という宣言 | ブラウザが古い解釈モードになり、表示が崩れる |
| `<html lang="ja">` | 文書全体。日本語であることを示す | 翻訳機能やスクリーンリーダーが誤動作する |
| `<head>` | ページの**設定**を書く場所。画面には出ない | — |
| `<meta charset="UTF-8">` | 文字コードの指定 | **日本語が文字化けする** |
| `<meta name="viewport" ...>` | スマホでの表示幅の指定 | **スマホで極小表示になる** |
| `<title>` | タブに表示されるタイトル | タブに「無題」と出る。検索結果にも影響 |
| `<body>` | 画面に**表示される中身** | — |

> ⚠️ **`<head>` と `<body>` の混同**
> 画面に出したいものは、**必ず `<body>` の中**に書きます。`<head>` に書いても表示されません。
> 「書いたのに出ない」の原因の定番です。

### 表示してみる

VS Code で `index.html` を右クリック →「**Open with Live Server**」

ブラウザに「山田 太郎」と大きく表示されれば成功です。

> 💡 Live Server は保存すると自動でリロードされます。以降、保存するたびに結果を確認しながら進めてください。

## ✍️ 手を動かす③ ─ 中身を作っていく

`<body>` の中を、以下のように育てていきます。**一気に書かず、1ブロックずつ保存して確認**してください。

### 見出しと段落

```html
<body>
  <h1>山田 太郎</h1>
  <p>Web開発を学習中です。HTMLとCSSを勉強しています。</p>
</body>
```

**見出しは `h1` → `h2` → `h3` の順に使います。**

```html
<h1>大見出し（ページに1つだけ）</h1>
  <h2>中見出し</h2>
    <h3>小見出し</h3>
  <h2>中見出し</h2>
```

> ⚠️ **飛ばして使わない**
> `<h1>` の次にいきなり `<h3>` を使うのはNGです。「文字の大きさで選ぶ」からこうなります。**大きさはCSSで変えられる**ので、意味の順で選んでください。

### リスト

```html
  <h2>好きなもの</h2>
  <ul>
    <li>コーヒー</li>
    <li>散歩</li>
    <li>映画鑑賞</li>
  </ul>
```

| タグ | 意味 |
| --- | --- |
| `<ul>` | 順序のないリスト（Unordered List）。点が付く |
| `<ol>` | 順序のあるリスト（Ordered List）。番号が付く |
| `<li>` | リストの各項目（List Item） |

> ⚠️ **`<li>` は必ず `<ul>` か `<ol>` の中に入れます。** 単独では使えません。

> 💡 Emmet で `ul>li*3` + `Tab` と打つと、一瞬で骨組みができます。

### リンク

```html
  <h2>連絡先</h2>
  <p>
    メール：<a href="mailto:taro@example.com">taro@example.com</a>
  </p>
  <p>
    <a href="https://github.com/" target="_blank" rel="noopener">GitHub</a>
  </p>
```

| 属性 | 意味 |
| --- | --- |
| `href` | リンク先。**必須** |
| `target="_blank"` | 新しいタブで開く |
| `rel="noopener"` | `target="_blank"` とセットで書く（セキュリティ対策） |

> 💡 `rel="noopener"` を付けないと、リンク先のページから元のページを操作できてしまう脆弱性があります。**`target="_blank"` を書いたら、必ずセットで書く**と覚えてください。

### ここまでの完成形

```html
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>山田太郎のプロフィール</title>
</head>
<body>
  <h1>山田 太郎</h1>
  <p>Web開発を学習中です。HTMLとCSSを勉強しています。</p>

  <h2>好きなもの</h2>
  <ul>
    <li>コーヒー</li>
    <li>散歩</li>
    <li>映画鑑賞</li>
  </ul>

  <h2>連絡先</h2>
  <p>
    メール：<a href="mailto:taro@example.com">taro@example.com</a>
  </p>
</body>
</html>
```

## ⚠️ つまずきポイントまとめ

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| 日本語が「�」になる | `<meta charset="UTF-8">` がない、またはファイルがUTF-8で保存されていない | VS Code右下の文字コード表示を確認 |
| 書いたのに表示されない | `<head>` の中に書いている | `<body>` の中へ移動 |
| レイアウトが崩れる | 終了タグの閉じ忘れ | 開始タグを書いたら即座に終了タグも書く |
| 改行したのに反映されない | HTMLでは改行やスペースの連続は無視される | 段落は `<p>` で分ける |
| 半角スペースが1つにまとまる | HTMLの仕様 | CSSで余白を調整する（レッスン1-6） |

### 改行について（初学者が必ず引っかかる）

```html
<!-- これは1行で表示される -->
<p>
  こんにちは
  さようなら
</p>
```

**HTMLでは、ソース上の改行は「半角スペース1つ」として扱われます。**

段落を分けたいときは `<p>` を2つ書いてください。

```html
<p>こんにちは</p>
<p>さようなら</p>
```

> 💡 `<br>` で改行することもできますが、**「同じ段落の中での強制改行」（住所や詩など）に限って使う**のが正しい使い方です。段落の区切りには `<p>` を使います。

### 演習2（必須）

以下のHTMLには**5つの間違い**があります。すべて見つけて直してください。

```html
<!DOCTYPE html>
<html lang="ja">
<head>
  <title>間違い探し</title>
  <h1>これは見出しです</h1>
</head>
<body>
  <p>段落です
  <ul>
    <li>項目1</li>
    <li>項目2
  </ul>
  <a>リンクです</a>
</body>
</html>
```

<details>
<summary>答えを見る（自力でやってから開いてください）</summary>

1. `<meta charset="UTF-8">` がない → 日本語が文字化けする
2. `<h1>` が `<head>` の中にある → `<body>` の中に移動する
3. `<p>段落です` の終了タグ `</p>` がない
4. `<li>項目2` の終了タグ `</li>` がない
5. `<a>` に `href` 属性がない → リンクとして機能しない

さらに、`<meta name="viewport">` もないため、スマホで正しく表示されません（余裕があればこれも追加してください）。

</details>
