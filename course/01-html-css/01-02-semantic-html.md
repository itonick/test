## 📖 なぜ `<div>` ではダメなのか

`<div>` は「意味のないただの箱」です。全部 `<div>` でも見た目は同じに作れます。

```html
<!-- 全部 div で書いたHTML -->
<div class="header">
  <div class="logo">KOMOREBI COFFEE</div>
  <div class="nav">...</div>
</div>
<div class="main">
  <div class="section">...</div>
</div>
<div class="footer">...</div>
```

これを **div スープ** と呼びます。何が問題か。

| 困る人 | 何が起きるか |
| --- | --- |
| 検索エンジン | どこが本文で、どこがナビか判別できない。SEOで不利になる |
| スクリーンリーダー | 「見出しだけ拾い読み」「本文へスキップ」ができず、毎回ナビを読み上げる |
| ブラウザのリーダーモード | 本文を抽出できず、機能しない |
| チームの他の人 | `class="header"` を信じるしかない。CSSを消したら構造が消える |

セマンティックタグを使うと、**HTMLだけで構造が伝わります。**

```html
<!-- 意味のあるタグで書いたHTML -->
<header>
  <p class="logo">KOMOREBI COFFEE</p>
  <nav>...</nav>
</header>
<main>
  <section>...</section>
</main>
<footer>...</footer>
```

CSSを1行も書かなくても、**これがヘッダーで、これが本文だ**と誰にでもわかります。

> 💡 **`class` の名前は、コンピュータには何の意味もありません。**
> `class="header"` と書いても、ブラウザにとってはただの文字列です。意味を伝えるのはタグの種類だけです。

## ✍️ 手を動かす① ─ 主要タグを覚える

### 覚えるのは7つだけ

| タグ | 意味 | 1ページ内の数 |
| --- | --- | --- |
| `<header>` | ページや区画の**頭**。ロゴ、サイト名、ナビなど | 複数可 |
| `<nav>` | **主要な**ナビゲーション | 複数可（ただし主要なものだけ） |
| `<main>` | そのページの**主要コンテンツ** | **1つだけ** |
| `<section>` | 意味のある**区画**。見出しを持つのが原則 | 複数可 |
| `<article>` | それ単体で成立する**記事**。ブログ記事、商品カードなど | 複数可 |
| `<aside>` | 本筋から外れる**補足**。サイドバー、広告 | 複数可 |
| `<footer>` | ページや区画の**末尾**。著作権表示、サイトマップ | 複数可 |

### 迷ったときの判断フロー

```
その要素は…
│
├─ ページの主要コンテンツ全体？ ────────→ <main>
│
├─ 見出しを持つ、意味のあるまとまり？
│    │
│    ├─ 切り出して他所に置いても成立する？ → <article>
│    └─ このページの中の一区画？          → <section>
│
├─ ロゴ・サイト名・導入がある頭の部分？ ──→ <header>
├─ 主要なリンクの集まり？ ────────────────→ <nav>
├─ 本筋と関係ない補足？ ─────────────────→ <aside>
├─ 著作権・連絡先などの末尾情報？ ────────→ <footer>
│
└─ どれでもない（レイアウトのためだけ）？ → <div>
```

> ⚠️ **`<div>` を使ってはいけない、ではありません。**
> 「レイアウトのためだけの箱」には `<div>` が正解です。意味がないのに `<section>` を使うほうが問題です。
> **迷ったら `<div>`。意味が言えるときだけセマンティックタグ**、が安全です。

### `<section>` と `<article>` の違い

これが最も混乱するポイントです。判断基準は1つ。

> **切り出して他の場所に置いても、それだけで意味が通じるか？**

| 例 | 答え | タグ |
| --- | --- | --- |
| ブログの記事本文 | 通じる（単体でRSSに載せられる） | `<article>` |
| 商品一覧の中の1商品 | 通じる（単体で商品カードとして成立） | `<article>` |
| LPの「メニュー紹介」ブロック | 通じない（このページの一部） | `<section>` |
| LPの「アクセス」ブロック | 通じない | `<section>` |

> 💡 **`<section>` には原則、見出し（`h2` など）を付けます。**
> 見出しを付けられないなら、それは意味のある区画ではないので `<div>` が適切です。

VS Code で `komorebi` フォルダを開いてください（File → Open Folder）。

### index.html を書く

`index.html` に以下を書きます。

> 🖊 **これは手で打ってください。** タグの意味を意識しながら打つことが、このレッスンの目的です。
> Emmet を使うと速く打てます（`header>nav>ul>li*3>a` + `Tab` など）。

```html
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>KOMOREBI COFFEE｜木漏れ日の下で、一杯を。</title>
  <meta name="description" content="住宅街の小さな自家焙煎コーヒースタンド、KOMOREBI COFFEE の公式サイトです。">
  <link rel="stylesheet" href="css/style.css">
</head>
<body>

  <header class="site-header">
    <p class="logo">KOMOREBI COFFEE</p>
    <nav class="global-nav">
      <ul>
        <li><a href="#menu">MENU</a></li>
        <li><a href="#about">ABOUT</a></li>
        <li><a href="#access">ACCESS</a></li>
      </ul>
    </nav>
  </header>

  <main>

    <section class="hero">
      <h1>木漏れ日の下で、一杯を。</h1>
      <p>住宅街の小さな自家焙煎コーヒースタンド。</p>
    </section>

    <section id="menu" class="menu">
      <h2>MENU</h2>
      <p>季節ごとに、産地を変えてお出ししています。</p>
    </section>

    <section id="about" class="about">
      <h2>ABOUT</h2>
      <p>2019年、この街で焙煎を始めました。</p>
    </section>

    <section id="access" class="access">
      <h2>ACCESS</h2>
      <p>東京都〇〇区〇〇 1-2-3</p>
    </section>

  </main>

  <footer class="site-footer">
    <p>&copy; 2026 KOMOREBI COFFEE</p>
  </footer>

</body>
</html>
```

保存して、Live Server で開いてください。**装飾は何もありませんが、それで正解です。**

### いま書いたコードのポイント

| 書いたもの | 意図 |
| --- | --- |
| `<meta name="description">` | 検索結果に表示される説明文。SEOの基本 |
| `<title>` に店名＋キャッチ | タブと検索結果に出る。店名だけよりクリックされやすい |
| `<p class="logo">` | ロゴは**見出しではない**。`<h1>` はページの主題（ヒーローの文言）に使う |
| `<nav>` の中に `<ul>` | ナビゲーションは「リンクのリスト」なので、リストで書くのが正解 |
| `id="menu"` | ページ内リンク（`href="#menu"`）のジャンプ先 |
| `&copy;` | © の文字実体参照。直接 © と打っても動くが、こちらが確実 |

> ⚠️ **`<h1>` はどこに書くべきか**
> ロゴ（サイト名）を `<h1>` にする書き方も昔は一般的でしたが、**現在は「そのページの主題」に付ける**のが主流です。
> トップページなら「木漏れ日の下で、一杯を。」、メニューページなら「MENU」が `<h1>` になります。

### ページ内リンクが動くことを確認する

ブラウザで「MENU」のリンクをクリックしてください。ページが MENU の位置までスクロールします。

これは `<a href="#menu">` と `id="menu"` が対応しているからです。**`#` は「同じページの、このIDの場所へ」という意味**です。

> ⚠️ 動かない場合は、`href="#menu"` の `#` を忘れていないか、`id` のつづりが一致しているかを確認してください。IDは**大文字小文字を区別します。**

```
html

   ├─ header.site-header
   │  ├─ p.logo
   │  └─ nav.global-nav
   ├─ main
   │  ├─ section.hero
   │  ├─ section.menu
   │  ├─ section.about
   │  └─ section.access
   └─ footer.site-footer
```

**`main` の中に `header` が入っていたり、`section` が `body` 直下にあったりしたら、ネストが崩れています。**

> 🆘 **ここで詰まったら**（`div` だらけになって、どのタグを使えばいいか迷う）
> - **考え方**：迷ったら「この部分は**何**か」を日本語で言ってみる。「ページの頭」→ `header`、「主役の内容」→ `main`、「意味のまとまり」→ `section`。**言葉にできないものだけ `div`** にします
> - **判断に迷ったら、AIにこう聞く**（自分のHTMLを貼る）：
>   「このHTMLで、それぞれの `div` は `header`/`main`/`section`/`article`/`nav`/`footer` のどれに置き換えるのが適切ですか？ 理由も添えて、初心者向けに教えてください」

## ⚠️ つまずきポイントまとめ

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| ページ内リンクが飛ばない | `id` のつづり違い / `#` の書き忘れ | 大文字小文字も含めて一致させる |
| インデントがぐちゃぐちゃ | 手動でインデントしている | `Shift + Alt + F`（VS Code の整形）を使う |
| `<main>` が2つある | セクションごとに書いてしまった | `<main>` は1ページに1つだけ |
| `<section>` に見出しがない | 意味のない区画に section を使っている | `<div>` に変える |
| `<nav>` を全部のリンク集に使っている | 「主要な」ナビだけが `<nav>` | フッターの補助リンクなどは `<ul>` だけでよい |

### 演習2（必須）

以下のHTMLは**セマンティックに問題があります**。5か所見つけて直してください。

```html
<body>
  <div class="header">
    <h1>私のブログ</h1>
  </div>
  <main>
    <h3>記事一覧</h3>
    <section>
      <p>記事タイトル1</p>
      <p>本文...</p>
    </section>
  </main>
  <main>
    <div class="sidebar">人気記事</div>
  </main>
  <div class="footer">© 2026</div>
</body>
```

<details>
<summary>答えを見る（自力でやってから開いてください）</summary>

1. `<div class="header">` → `<header>` を使う
2. `<h3>記事一覧</h3>` → `h1` の次は `h2`。レベルを飛ばしている
3. `<section>` の中の `<p>記事タイトル1</p>` → 見出しなので `<h3>`（`h2` の下）にする。また、記事単体で成立するので `<article>` が適切
4. `<main>` が2つある → 1つにまとめる。サイドバーは `<aside>` として `<main>` の外に出す
5. `<div class="footer">` → `<footer>` を使う

修正例:

```html
<body>
  <header>
    <h1>私のブログ</h1>
  </header>
  <main>
    <h2>記事一覧</h2>
    <article>
      <h3>記事タイトル1</h3>
      <p>本文...</p>
    </article>
  </main>
  <aside>
    <h2>人気記事</h2>
  </aside>
  <footer>
    <p>&copy; 2026</p>
  </footer>
</body>
```

</details>
