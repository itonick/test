## 📖 Grid と Flexbox、どっちを使う？

| | Flexbox | Grid |
| --- | --- | --- |
| 得意 | **1方向**（横 or 縦）に並べる | **2次元**（行と列）に配置する |
| 発想 | 中身のサイズから決まる | **先に枠を決めて**、そこに入れる |
| 向いている例 | ナビ、ボタン列、カード1行 | ページ全体、写真ギャラリー、複雑な配置 |

### 判断のコツ

> **「行と列、両方を意識するか？」**
> - Yes → **Grid**
> - No（1列に並べるだけ） → **Flexbox**

> 💡 **両方使うのが普通です。** ページ全体を Grid で組み、その中の各パーツを Flexbox で並べる、という組み合わせが実務では最も多いパターンです。
> どちらか一方を選ぶ必要はありません。

## ✍️ 手を動かす① ─ Grid の基本

```css
.grid {
  display: grid;
  grid-template-columns: 200px 200px 200px;  /* 3列 */
  gap: 16px;
}
```

```
┌──────┬──────┬──────┐
│ 200  │ 200  │ 200  │
├──────┼──────┼──────┤
│      │      │      │  ← 子が4つ以上なら自動で次の行へ
└──────┴──────┴──────┘
```

**子には何も書きません。** 親が枠を決め、子が順に入っていきます。

### `fr` 単位 — Grid 最大の武器

`fr` は「余ったスペースの分け前（fraction）」です。

```css
grid-template-columns: 1fr 1fr 1fr;      /* 3等分 */
grid-template-columns: 2fr 1fr;          /* 2:1 の比率 */
grid-template-columns: 240px 1fr;        /* 左240px固定、右は残り全部 */
grid-template-columns: 1fr 3fr 1fr;      /* 中央を広く */
```

> 💡 **`%` ではなく `fr` を使ってください。**
> `width: 33.33%` を3つ並べると、`gap` の分だけはみ出します。`fr` は **gap を引いた残り**を分配するので、はみ出しません。
> 「3等分したいのに、なぜか横スクロールが出る」問題は、`fr` を使えば起きません。

### `repeat()` で繰り返しを短く

```css
grid-template-columns: repeat(3, 1fr);        /* 1fr 1fr 1fr と同じ */
grid-template-columns: repeat(4, 200px);      /* 200px × 4 */
grid-template-columns: repeat(2, 1fr) 300px;  /* 1fr 1fr 300px */
```

### 行の指定

```css
grid-template-rows: 100px auto 80px;  /* ヘッダー / 本文 / フッター */
gap: 16px 24px;                       /* 行間16px、列間24px */
row-gap: 16px;
column-gap: 24px;
```

## ✍️ 手を動かす② ─ `auto-fit` + `minmax()`（超重要）

**メディアクエリを書かずにレスポンシブになる**、Grid の目玉機能です。

```css
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
  gap: 24px;
}
```

これだけで、以下が実現します。

```
画面幅 1200px → 4列
画面幅  900px → 3列
画面幅  600px → 2列
画面幅  400px → 1列
```

### 何が起きているのか

| 部分 | 意味 |
| --- | --- |
| `repeat(auto-fit, ...)` | **入るだけ列を作る** |
| `minmax(240px, 1fr)` | 各列は**最小240px、最大は余りを均等に** |

つまり「240px 以上を保てる限り列を増やし、無理なら折り返す」という指示です。

> 💡 **カードを並べるレイアウトは、ほぼこの1行で解決します。**
> これを知っているかどうかで、CSSの記述量が3倍変わります。**このレッスンで一番覚えて帰ってほしいのはこれです。**

### `auto-fit` と `auto-fill` の違い

| | 要素が少ないとき |
| --- | --- |
| `auto-fit` | **要素が伸びて**、余白を埋める |
| `auto-fill` | 空の列が残り、要素は伸びない |

```
要素が2つ、幅1200pxのとき

auto-fit:   [────要素1────][────要素2────]
auto-fill:  [要素1][要素2][空][空]
```

**基本は `auto-fit`** を使ってください。

> 🆘 **ここで詰まったら**（カードが並ばない／1列のまま／はみ出す）
> - **まず確認**：① `display: grid` と `grid-template-columns` は**カードの「親」**（`.cards` など）に付けたか（子に付けても効きません）② `minmax(240px, 1fr)` の `240px` が画面幅より大きくないか（大きいと1列になります。狭い画面向けには `minmax(min(100%, 240px), 1fr)`）③ 親に十分な幅があるか
> - **開発者ツールで確認**：F12 で親要素を選び、Styles の `display: grid` の横に出る **`grid` バッジ**を押すと、列の境界線が可視化されます
> - **直らなければ、AIにこう聞く**（HTMLとCSSを貼る）：
>   「Grid でカードを並べたいのに1列のままです。どこに何を指定すべきか、私のコードの原因を教えてください」

## ✍️ 手を動かす③ ─ 位置を指定する

### 番号で指定

```css
.item {
  grid-column: 1 / 3;   /* 1本目の線から3本目の線まで（＝2列分） */
  grid-row: 2 / 4;      /* 2本目から4本目（＝2行分） */
}
```

**Gridは「線」で数えます。** 3列なら、線は4本です。

```
線1    線2    線3    線4
 │      │      │      │
 │ 列1  │ 列2  │ 列3  │
 │      │      │      │
```

### `span` で「何個分」と書く

```css
.item {
  grid-column: span 2;   /* 2列分 */
  grid-row: span 2;      /* 2行分 */
}
```

こちらのほうが直感的で、実務でもよく使われます。

### エリア名で指定（可読性が最高）

```css
.layout {
  display: grid;
  grid-template-columns: 240px 1fr;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
  gap: 24px;
  min-height: 100vh;
}

.layout > header  { grid-area: header; }
.layout > .side   { grid-area: sidebar; }
.layout > main    { grid-area: main; }
.layout > footer  { grid-area: footer; }
```

**CSSを見るだけでレイアウトが目に浮かびます。** 管理画面やブログのような固定レイアウトに最適です。

> 💡 空白を作りたいときは `.`（ドット）を書きます。
>
> ```css
> grid-template-areas:
>   "header header"
>   "...... main";
> ```

## ✍️ 手を動かす④ ─ Grid で中央寄せ

```css
.center {
  display: grid;
  place-items: center;   /* これだけで縦横中央 */
  min-height: 400px;
}
```

Flexbox の3行が、**Grid なら2行**になります。

| やりたいこと | Grid の書き方 |
| --- | --- |
| 縦横中央 | `place-items: center` |
| 横だけ中央 | `justify-items: center` |
| 縦だけ中央 | `align-items: center` |
| 中身全体を中央に寄せる | `place-content: center` |

## ✍️ 手を動かす⑤ ─ カフェLPをGridで組み直す

### ① メニューを Grid に

Flexbox で書いていた `.menu-list` を、Grid に置き換えます。

```css
/* Before（Flexbox）
.menu-list {
  display: flex;
  flex-wrap: wrap;
  gap: 32px;
}
.menu-item { flex: 1 1 240px; }
*/

/* After（Grid）— 子の指定が不要になる */
.menu-list {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
  gap: 40px 32px;
  margin-top: 40px;
}

.menu-item {
  padding: 0;
  border-bottom: none;
}
```

**違いを体感してください。** Flexbox版では、最後の行の要素が横に伸びてしまいます（`flex: 1` のため）。Grid版なら、**列幅が常に揃います**。

```
Flexbox（4つのとき）        Grid（4つのとき）
┌────┬────┬────┐          ┌────┬────┬────┐
│ 1  │ 2  │ 3  │          │ 1  │ 2  │ 3  │
├────┴────┴────┤          ├────┼────┴────┘
│      4       │ ←伸びる  │ 4  │        ←揃う
└──────────────┘          └────┘
```

> 💡 **「カードの列幅を揃えたいなら Grid」** が、実務での定番判断です。

### ② アクセス情報を Grid に

```css
/* ==========================================================
   8. アクセス情報（dl）
   ========================================================== */

.info {
  display: grid;
  grid-template-columns: 96px 1fr;
  gap: 12px 16px;
  margin-top: 24px;
  max-width: 480px;
}

.info dt {
  font-family: var(--font-en);
  font-size: var(--fs-xs);
  letter-spacing: .12em;
  color: var(--color-accent);
  margin: 0;
}

.info dd {
  margin: 0;
  color: var(--color-text-light);
}
```

`<dl>` は `dt` と `dd` が交互に並ぶので、**2列の Grid にすると自動できれいに揃います**。Flexbox より圧倒的に簡単です。

### ③ ABOUT を2カラムに

```css
/* ==========================================================
   9. ABOUT
   ========================================================== */

.about {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
  gap: 32px 48px;
  align-items: start;
}

.about h2 {
  grid-column: 1 / -1;   /* 見出しは全幅を使う */
}
```

> 💡 **`grid-column: 1 / -1` は「最初の線から最後の線まで」= 全幅**という定番の書き方です。
> 列数がいくつでも全幅になるので、`auto-fit` と組み合わせるときに重宝します。

## ⚠️ つまずきポイントまとめ

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| Gridが効かない | 子に `display: grid` を書いた | **親**に書く |
| 列が均等にならない | `%` を使っている | `fr` を使う |
| 3等分したのに横スクロールが出る | `33.33%` + `gap` ではみ出している | `repeat(3, 1fr)` にする |
| 要素が少ないとき伸びない | `auto-fill` を使っている | `auto-fit` にする |
| `grid-template-areas` が効かない | エリア名の対応が取れていない / 長方形になっていない | 各行の列数を揃える。エリアは長方形でなければならない |
| 直下の子以外に効かない | Grid も**直下の子**にのみ効く | HTML構造を見直す |
| 高さが揃わない | `align-items` が `start` になっている | 初期値の `stretch` に戻す |

### デバッグの決定打

**開発者ツールで、`display: grid` の要素の横に `grid` バッジが出ます。**

クリックすると、**グリッド線と、線の番号が画面に重ねて表示されます**。`grid-column: 2 / 4` が実際にどこを指しているかが一目でわかります。

さらに、Elements パネル下部の **Layout** タブで、線番号やエリア名の表示をカスタマイズできます。

<details>
<summary>答えを見る</summary>

```
┌────┬────┬────┬────┐
│    A    │    B    │
├────┼────┴────┴────┤
```
