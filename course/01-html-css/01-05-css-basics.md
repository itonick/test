## 📖 CSSの3つの読み込み方

| 方法 | 書き方 | 使うべきか |
| --- | --- | --- |
| **外部CSS** | `<link rel="stylesheet" href="css/style.css">` | ✅ **これを使う** |
| 内部CSS | `<head>` の中に `<style>` を書く | 一時的な検証のみ |
| インラインCSS | `<p style="color: red;">` | ❌ 基本使わない |

外部CSSを使う理由は3つ。

1. **1つのCSSを全ページで共有できる**（100ページあっても修正は1か所）
2. HTMLが構造だけになり、読みやすくなる
3. ブラウザがCSSをキャッシュするので、2ページ目以降が速い

> ⚠️ **インラインスタイルは、後で詳細度の地獄を生みます。**
> `style="..."` はほぼ最強の優先度を持つため、外部CSSから上書きできなくなります。JavaScriptで動的に変える場合を除き、使わないでください。

## ✍️ 手を動かす① ─ CSSの基本形

```css
セレクタ {
  プロパティ: 値;
}
```

具体例。

```css
h1 {
  color: #333333;
  font-size: 32px;
}
```

| 部分 | 名前 | 意味 |
| --- | --- | --- |
| `h1` | セレクタ | **どの要素に** |
| `color` | プロパティ | **何を** |
| `#333333` | 値 | **どうする** |
| `;` | セミコロン | 1行の終わり。**最後の行も付ける** |

> ⚠️ **セミコロンの書き忘れ**
> 1行目のセミコロンを忘れると、**2行目も無効になります**。しかもエラーは出ません。
> CSSが効かないときは、まず直前の行のセミコロンを確認してください。

### コメント

```css
/* これはコメント。実行されない */
h1 {
  color: red; /* 行末にも書ける */
}
```

CSSに `//` は使えません。**必ず `/* */`** です。

## ✍️ 手を動かす② ─ セレクタの種類

### 基本の3つ

```css
/* 要素セレクタ：そのタグ全部 */
p { color: #555; }

/* クラスセレクタ：class="box" の要素（何個でも使える） */
.box { padding: 20px; }

/* IDセレクタ：id="header" の要素（ページに1つだけ） */
#header { background: #fff; }
```

**基本はクラスセレクタを使います。** 理由は次の通り。

| セレクタ | 使いどころ | 注意 |
| --- | --- | --- |
| 要素 | リセットや全体の基本設定 | 影響範囲が広すぎる |
| **クラス** | **ほとんどのスタイリング** | 再利用できる |
| ID | ページ内リンクのアンカー、JSからの取得 | 詳細度が高すぎてCSS向きでない |

> 💡 **IDをCSSに使わない理由**：詳細度が高すぎて、後から上書きできなくなるためです。
> `id="menu"` はページ内リンクの目印として使い、装飾は `class="menu"` で行う——これが実務での定石です。

### 組み合わせセレクタ

```css
/* 複数指定（カンマ）：h1 と h2 の両方に */
h1, h2 { font-weight: 700; }

/* 子孫セレクタ（スペース）：.nav の中にある全ての a */
.nav a { text-decoration: none; }

/* 子セレクタ（>）：.nav の直下の li だけ */
.nav > li { margin: 0; }

/* 複合（スペースなし）：class に card と featured の両方を持つ要素 */
.card.featured { border: 2px solid gold; }
```

> ⚠️ **スペースの有無で意味が変わります。**
>
> ```css
> .card .title { }  /* .card の中にある .title（子孫） */
> .card.title { }   /* .card と .title の両方を持つ要素（同一） */
> ```
>
> これは初学者が最も混乱する箇所です。**スペース＝「〜の中の」**と読んでください。

### 疑似クラス

要素の「状態」に応じたスタイルです。

```css
a:hover      { color: #c00; }  /* マウスを乗せたとき */
a:focus      { outline: 2px solid; }  /* キーボードで選択されたとき */
a:visited    { color: purple; }  /* 訪問済みのリンク */
li:first-child { margin-top: 0; }  /* 最初の子 */
li:last-child  { border-bottom: none; }  /* 最後の子 */
li:nth-child(2n) { background: #f5f5f5; }  /* 偶数番目 */
input:focus  { border-color: #333; }
button:disabled { opacity: .5; }
```

> ⚠️ **`:focus` のスタイルを消さないでください。**
> `outline: none;` と書く人がいますが、これをやるとキーボードだけで操作する人が**いま自分がどこにいるかわからなくなります**。
> 見た目が気に入らないなら、消すのではなく**別のスタイルに置き換えて**ください。

## ✍️ 手を動かす③ ─ 詳細度（優先順位）

同じ要素に複数のスタイルが当たったとき、どれが勝つかのルールです。

### 優先順位の表

| 順位 | 種類 | 例 | 点数 |
| --- | --- | --- | --- |
| 1（最強） | `!important` | `color: red !important;` | — |
| 2 | インラインスタイル | `style="color: red"` | 1000 |
| 3 | ID | `#header` | 100 |
| 4 | クラス・属性・疑似クラス | `.box` `[type="text"]` `:hover` | 10 |
| 5（最弱） | 要素・疑似要素 | `div` `::before` | 1 |

### 計算例

```css
p               { color: blue; }   /* 1点 */
.text           { color: green; }  /* 10点 */
.box p          { color: orange; } /* 10 + 1 = 11点 */
#main .box p    { color: red; }    /* 100 + 10 + 1 = 111点 ← 勝ち */
```

### 同点の場合は「後に書いたほうが勝つ」

```css
.btn { color: blue; }
.btn { color: red; }   /* ← こちらが勝つ */
```

> 💡 だから、**CSSファイルは「共通 → 個別」の順で書きます。** 逆にすると、共通スタイルが個別を上書きしてしまいます。

### `!important` を使ってはいけない理由

```css
.btn { color: red !important; }
```

一度使うと、それを上書きするには**さらに `!important` が必要**になります。数か月後には全行が `!important` になり、優先順位という仕組みそのものが機能しなくなります。

**負けているときは、セレクタを見直すのが正解です。**

```css
/* ❌ 力技 */
.btn { color: red !important; }

/* ✅ 詳細度を1段階上げる */
.card .btn { color: red; }
```

> ⚠️ 唯一の例外は、**外部ライブラリのスタイルをどうしても上書きできないとき**です。自分が書いたCSS同士では使いません。

## ✍️ 手を動かす④ ─ カフェLPにベーススタイルを当てる

`komorebi/css/style.css` を開いて、以下を書いてください。

> 🖊 **手で打ってください。** 各ブロックの意味を確認しながら進めます。
> 完成形は `code/01-05/css/style.css` にあります（📋 コピペ可）。

```css
/* ==========================================================
   1. リセット・基本設定
   ========================================================== */

/* すべての要素で、width に padding と border を含める */
*,
*::before,
*::after {
  box-sizing: border-box;
}

/* ブラウザ標準の余白を消す */
body,
h1, h2, h3, p,
ul, ol, li,
figure, dl, dd {
  margin: 0;
  padding: 0;
}

/* リストの点・番号を消す */
ul, ol {
  list-style: none;
}

/* 画像をブロック要素にして、はみ出しを防ぐ */
img {
  display: block;
  max-width: 100%;
  height: auto;
}

/* リンクの下線を消し、色を継承させる */
a {
  color: inherit;
  text-decoration: none;
}

/* フォーム部品にフォントを継承させる（初期状態では継承されない） */
input, textarea, select, button {
  font: inherit;
  color: inherit;
}


/* ==========================================================
   2. カラーとフォントの定義（カスタムプロパティ）
   ========================================================== */

:root {
  --color-text: #2b2723;
  --color-text-light: #6b6259;
  --color-bg: #fdfcfa;
  --color-accent: #8a5a3b;
  --color-border: #e6e0d8;

  --font-base: "Hiragino Sans", "Noto Sans JP", system-ui, sans-serif;
  --font-en: "Helvetica Neue", Arial, sans-serif;
}


/* ==========================================================
   3. ベーススタイル
   ========================================================== */

body {
  font-family: var(--font-base);
  font-size: 16px;
  line-height: 1.8;
  color: var(--color-text);
  background-color: var(--color-bg);
}

h1, h2, h3 {
  line-height: 1.4;
  font-weight: 700;
}

h1 { font-size: 32px; }
h2 { font-size: 24px; }
h3 { font-size: 18px; }

p {
  color: var(--color-text-light);
}

a:hover {
  color: var(--color-accent);
}

a:focus-visible {
  outline: 2px solid var(--color-accent);
  outline-offset: 2px;
}
```

保存して、ブラウザを確認してください。

- リストの点が消えた
- 見出しと本文の大きさに差がついた
- 本文がグレーになった
- リンクにマウスを乗せると色が変わる

### カスタムプロパティ（CSS変数）

```css
:root {
  --color-accent: #8a5a3b;
}

.btn {
  background-color: var(--color-accent);
}
```

**色やフォントを1か所で管理できる仕組み**です。

| 書き方 | 意味 |
| --- | --- |
| `--名前: 値;` | 定義（`:root` に書くとページ全体で使える） |
| `var(--名前)` | 使用 |

> 💡 **これを最初に導入する価値は絶大です。**
> 「アクセントカラーを変えたい」となったとき、`:root` の1行を変えるだけで全体が変わります。
> 変数を使わないと、CSSファイル中の同じ色を全部探して置換することになります。

## ⚠️ つまずきポイントまとめ ─ CSSが効かないとき

**チェックリスト（上から順に）**

```
1. CSSファイルは読み込まれているか？
   → 開発者ツール → Network タブで style.css が 404 でないか確認
   → <link rel="stylesheet" href="..."> の rel を書き忘れていないか

2. セレクタは合っているか？
   → 開発者ツール → Elements で要素を選び、右の Styles に
      そのルールが出てくるか確認
   → .box と #box、.card .title と .card.title の取り違え

3. 詳細度で負けていないか？
   → Styles パネルで、打ち消し線が引かれたプロパティを探す
      → 引かれていたら、負けている

4. 書式は正しいか？
   → セミコロンの書き忘れ（直前の行も確認）
   → { } の対応
   → 全角スペース・全角記号の混入

5. キャッシュではないか？
   → Ctrl + Shift + R でスーパーリロード
```

> 💡 **開発者ツールの Styles パネルは、CSSデバッグの主戦場です。**
> 「効かない」と悩む前に、まず要素を選択して Styles を見る。これだけで9割は原因がわかります。詳しくはレッスン1-12で扱います。

### その他

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| 1つのプロパティだけ効かない | そのプロパティ名のスペルミス | 開発者ツールで、そのプロパティに⚠が出ていないか確認 |
| 一部の要素だけ効かない | 詳細度で負けている | 打ち消し線を探す |
| 全部効かない | ファイルが読み込まれていない | Network タブで404を確認 |
| 単位を忘れた | `font-size: 16;` は無効 | 数値には `px` `rem` `%` などの単位が必要（`0` と `line-height` を除く） |

- [ ] `.site-footer` の文字を小さく（13px）、中央寄せにする

### 演習2（必須）

以下のCSSが「効かない」原因を、それぞれ答えてください。

```html
<div class="card">
  <p class="title">タイトル</p>
</div>
```

```css
/* ① */
.card.title { color: red; }

/* ② */
.card p { color: blue }
.card p { font-size: 20px; }

/* ③ */
.Card .title { color: green; }

/* ④ */
p { font-size: 16; }

/* ⑤ */
#main .title { color: orange; }
.title { color: purple; }
```

<details>
<summary>答えを見る（自力でやってから開いてください）</summary>

① **スペースがない**。`.card.title` は「card と title の両方を持つ要素」の意味。この HTML にはそんな要素がないので効かない。正しくは `.card .title`。

② **1行目のセミコロンがない**。`color: blue` の後に `;` がないため、この宣言自体は効くが（ブロック最後なので）、**もし後ろに宣言が続いていたらそれが無効になる**。この例では別ブロックなので font-size は効く。ただし**セミコロンは必ず書く習慣**にする。

③ **大文字小文字が違う**。CSSのクラスセレクタは大文字小文字を区別する。`.Card` と `.card` は別物。

④ **単位がない**。`font-size: 16;` は無効。`16px` と書く。

⑤ **詳細度で負けている**。`#main .title`（110点）が `.title`（10点）に勝つので、`purple` は適用されない。ただし HTML に `#main` がなければ、そもそもマッチしないので `purple` が効く。

</details>

### 演習3（挑戦）

カスタムプロパティを使って、**ダークテーマを1行で切り替えられる**ようにしてください。

- [ ] `:root` の下に、以下を追加する

```css
@media (prefers-color-scheme: dark) {
  :root {
    /* ここに、暗い配色の値を書く */
  }
}
```

- [ ] OSの設定をダークモードにして、配色が変わることを確認する

> 💡 変数だけを再定義すれば、他のCSSは1行も書き換えずにテーマが切り替わります。これが変数を使う最大のメリットです。
