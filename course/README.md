# AIと一緒につくる Web アプリ開発入門

**HTML / CSS / JavaScript から PHP・Laravel まで、AIを「使いこなしながら」ゼロから学ぶ全 7 部・全 83 レッスン**

## コンセプト

**パソコンにはじめて触れる人でも、手を動かしながら「自分で作れる力」を身につけられるように設計した教材です。**
第0部の前に「0-0 パソコンの基本操作」を用意し、マウス・キーボード・日本語入力・ファイル操作から始められます。そして学び終えたあと、**その力を仕事につなげていく道のり**（巻末「[キャリアの築き方](appendix/career-guide.md)」）まで扱います。

> 💬 **正直な但し書き**：習得にかかる時間には個人差があり、「必ず稼げる」「誰でも簡単に・短期間で」といった保証はできません。近道の代わりに、**つまずきやすい所を一つずつ潰し、続けられる設計**にすることで、着実に前に進めるようにしています。

## この教材が解決すること

プログラミング学習の挫折率は高いと言われます。原因のほとんどは「才能」ではなく、次の 4 つです。

| 挫折の原因 | 本教材の対策 |
| --- | --- |
| **環境構築で詰む** | 第0部で Windows / Mac 別に画面つきで手順化。うまくいかない時の分岐も全部書く |
| **エラーが読めず止まる** | 全レッスンに「つまずきポイント」節。巻末に**エラー図鑑**（症状 → 原因 → 直し方） |
| **写経しても身につかない** | 「読む → 手を動かす → **AIに説明させる** → 自分で変える」の4ステップを毎回踏む |
| **AIに丸投げして詰む** | AI活用を**独立した学習項目**として扱う。聞き方・検証の仕方・任せてはいけない範囲まで教える |

## 対象読者

- **パソコンを触ったことがない人**（第0部の前に「0-0 パソコンの基本操作」から始められます）
- プログラミング完全未経験〜HTMLを少し触ったことがある人
- ChatGPT / Claude を「なんとなく」使っているが、開発で活かせていない人
- 転職・副業・社内DXのために「動くものを1人で作りきる力」が欲しい人

**必要なもの**: パソコン（Windows / Mac どちらでも可）とインターネット環境のみ。有料ソフトは一切不要です。

## 到達点

修了時、あなたは以下ができるようになります。

- [ ] HTML / CSS でデザインカンプ通りのページを組める（レスポンシブ対応込み）
- [ ] JavaScript で動きのある UI（モーダル、タブ、フォームバリデーション）を実装できる
- [ ] PHP でフォーム送信・セッション・ファイル操作を扱える
- [ ] MySQL でテーブル設計を行い、SQL でデータを操作できる
- [ ] Laravel で認証つき CRUD アプリを一人で作りきれる
- [ ] **AI に的確に質問し、返ってきたコードの正しさを自分で検証できる**
- [ ] **AIや情報を鵜呑みにせず、根拠を確かめて判断できる（クリティカルシンキング）**
- [ ] **「何を・なぜ作るか」を自分で決め、仕様に落とせる（AIに任せられない力）**
- [ ] 制作物を GitHub に公開し、ポートフォリオとして提示できる
- [ ] 学び終えたあと、**その力を仕事につなげていく現実的な順番**（巻末「キャリアの築き方」）を持てる

## 全レッスンに共通する構成

どのレッスンも同じ順番で進みます。慣れると迷いません。

1. **◎ このレッスンのゴール** — 終わったら何ができるか
2. **📸 完成イメージ** — 先にゴールの絵を見る
3. **📖 なぜこれが必要か** — 動機づけ。丸暗記を防ぐ
4. **✍️ 手を動かす** — 1手順ずつ、コピペではなく理解しながら
5. **⚠️ つまずきポイント** — ここで失敗しやすい、という先回り
6. **🤖 AIに聞いてみよう** — そのまま使えるプロンプト例
7. **🔧 やってみよう（演習）** — 自分の手で変える
8. **✅ 章末チェック** — 理解度セルフチェック
