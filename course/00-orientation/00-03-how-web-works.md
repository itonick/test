# 0-3 Webサイトが表示される仕組み

> 🎯 **このレッスンのゴール**
> - URLを打ってからページが出るまでに何が起きているかを説明できる
> - フロントエンドとバックエンドの境界がわかる
> - これから学ぶ HTML / CSS / JS / PHP / MySQL が、どこで動くものか地図上に置ける

所要 40分 / 難度 🟢

---

## なぜ最初にこれをやるのか

多くの教材は、いきなり `<h1>Hello</h1>` から始まります。それでも書けるようになりますが、**後で必ず迷子になります**。

- 「PHPで書いた `echo` が、なぜブラウザに文字として出るの？」
- 「JavaScript でデータベースを直接触れないのはなぜ？」
- 「ローカルでは動くのに、サーバーに上げると動かないのはなぜ？」

これらは全部、**動いている場所**の理解で解けます。先に地図を持っておきましょう。

## 📸 全体像

```
┌──────────────── あなたのパソコン ────────────────┐
│                                                   │
│   ブラウザ（Chrome）                              │
│   ┌─────────────────────────────────────┐        │
│   │  HTML  … 構造（骨組み）              │        │
│   │  CSS   … 見た目（服）                │        │
│   │  JS    … 動き（筋肉）                │        │
│   └─────────────────────────────────────┘        │
│                     ↑ ↓                           │
└─────────────────────┼─────────────────────────────┘
                      │ インターネット（HTTP）
                      │ ①リクエスト  ②レスポンス
┌─────────────────────┼─────────────────────────────┐
│   Webサーバー        ↓                             │
│   ┌─────────────────────────────────────┐         │
│   │  PHP   … 処理を考える（頭脳）        │         │
│   └─────────────────────────────────────┘         │
│                     ↑ ↓                            │
│   ┌─────────────────────────────────────┐         │
│   │  MySQL … データを覚える（記憶）      │         │
│   └─────────────────────────────────────┘         │
└───────────────────────────────────────────────────┘
```

- **フロントエンド**＝ブラウザの中で動くもの → HTML / CSS / JavaScript
- **バックエンド**＝サーバーの中で動くもの → PHP / MySQL

この教材の第1・2部でフロントエンド、第3・4・5部でバックエンドを学びます。

## URLを打ってから表示されるまで（6ステップ）

`https://example.com/shop` をブラウザに入力したとします。

### ① ドメイン名を住所に変換する（DNS）

`example.com` という名前を、`93.184.216.34` のような **IPアドレス**（インターネット上の住所）に変換します。この電話帳の役割をするのが **DNS** です。

> 💡 「サイトが表示されない」時、原因がDNSであることは実は結構あります。

### ② サーバーにリクエストを送る

ブラウザがサーバーに「`/shop` のページをください」とお願いします。これが **HTTPリクエスト**。

```http
GET /shop HTTP/1.1
Host: example.com
```

### ③ サーバーが処理する

ここが**バックエンド**の出番です。

- 静的ファイル（HTML/CSS/画像）なら、そのまま返す
- PHPファイルなら、**PHPが実行されて** HTML を生成する
- 必要なら MySQL に問い合わせてデータを取り出す

```
リクエスト → PHP が実行される → MySQL に「商品一覧ちょうだい」
                              ← 商品データが返る
            PHP が HTML を組み立てる
```

> ⚠️ **超重要**
> **PHPのコードそのものはブラウザに届きません。** PHPが「実行された結果のHTML」だけが届きます。
> だから、PHPファイルをブラウザで「ソースを表示」しても、PHPコードは見えません。
> 逆に **JavaScript のコードは丸見え**です。パスワードなどを JS に書いてはいけない理由がこれです。

### ④ レスポンスが返る

サーバーが HTML を返します。一緒に **ステータスコード**という数字が付いてきます。

| コード | 意味 | よく見る場面 |
| --- | --- | --- |
| 200 | 成功 | 正常表示 |
| 301 / 302 | 転送 | URLが変わった |
| 403 | 権限がない | ファイルのパーミッション設定ミス |
| **404** | 見つからない | **ファイル名・パスの打ち間違い** |
| **500** | サーバー内部エラー | **PHPのコードにエラーがある** |

> ⚠️ **つまずきポイント**
> 学習中にいちばん出会うのは **404** と **500** です。
> - **404** → あなたのコードは悪くない。**ファイルの置き場所かURLが間違っている**
> - **500** → あなたのPHPコードにエラーがある。**エラーログを見れば原因が書いてある**（レッスン3-1で見方を学びます）
>
> この2つを見分けられるだけで、デバッグ時間が半分になります。

### ⑤ ブラウザがHTMLを解釈して描画する

ブラウザは HTML を上から読み、CSS を適用し、JavaScript を実行して、画面を組み立てます。

### ⑥ 追加のリクエストが飛ぶ

HTML の中に `<img src="logo.png">` や `<link href="style.css">` があれば、それぞれ**別のリクエスト**として取りに行きます。

> 💡 1ページの表示に、実は数十回のリクエストが飛んでいます。Chrome の開発者ツール → Network タブで実際に見られます（レッスン1-12で使います）。

---

## ✍️ 手を動かす：実際に見てみる

1. Chrome で任意のサイトを開く
2. **F12**（Mac は `Cmd + Option + I`）で開発者ツールを開く
3. **Network** タブをクリック
4. ページをリロード（`F5` / `Cmd + R`）

ずらっと並んだ行が、①〜⑥で説明したリクエストです。いちばん上の行をクリックすると、Status Code（200など）が見られます。

次に **Elements** タブを開き、表示中のHTMLを眺めてください。今はわからなくて構いません。「これがHTMLか」と思えれば十分です。

## 用語を整理しておく

| 用語 | ざっくり言うと |
| --- | --- |
| クライアント | サービスを使う側。ここではブラウザ |
| サーバー | サービスを提供する側のコンピュータ |
| HTTP / HTTPS | ブラウザとサーバーの会話のルール。HTTPSは暗号化されている |
| リクエスト | 「これください」というお願い |
| レスポンス | 「はいどうぞ」という返事 |
| フロントエンド | ブラウザ側で動く部分 |
| バックエンド | サーバー側で動く部分 |
| ローカル環境 | 自分のPCの中に作った練習用サーバー |
| 本番環境 | 実際に世界に公開されているサーバー |

> 🆘 **ここで詰まったら**（用語が多くて頭に入らない）
> - **考え方**：この段階では**全部を暗記しなくてOK**です。「リクエスト＝お願い」「レスポンス＝返事」くらいの雰囲気で先に進み、各部で実物に触れると腹落ちします
> - **理解でつまずいたら、AIに例え話で説明させる**：
>   「『クライアントとサーバー』『リクエストとレスポンス』の関係を、プログラミング未経験者に向けて、レストランやコンビニなど身近な例えで説明してください。専門用語は最後にまとめてください」
> - こうやって「自分がわかる例え」に置き換えて説明させるのは、AIの得意技であり、独学の強い味方です。
