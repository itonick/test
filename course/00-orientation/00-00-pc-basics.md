## このレッスンについて

**この教材は、パソコンにはじめて触れる方でも始められるように作っています。**
とはいえ、いきなりプログラミングの前に、PCの基本操作に少し慣れておくと、この先がぐっと楽になります。

> 💬 **正直にお伝えします。**

## STEP 1 ─ マウス／トラックパッドの操作

| 操作 | やり方 | 使う場面 |
| --- | --- | --- |
| クリック | 左ボタンを1回押す | ボタンやリンクを押す |
| ダブルクリック | 左ボタンを素早く2回 | ファイルやアプリを開く |
| 右クリック | 右ボタンを1回 | メニューを出す（コピー等） |
| ドラッグ | 押したまま動かして離す | 文字を選ぶ・移動する |
| スクロール | ホイールを回す／2本指で上下 | 画面を上下に動かす |

> 🖐 **やってみよう**：このページを、スクロールで下まで動かして、また上まで戻してみてください。それだけで練習になります。

---

## STEP 2 ─ キーボードの基本

最初に覚えるキーは、これだけで十分です。

| キー | 役割 |
| --- | --- |
| `Enter`（Return） | 決定・改行 |
| `Space` | 空白／日本語の変換 |
| `Backspace` | カーソルの**左**の文字を消す |
| `Delete` | カーソルの**右**の文字を消す |
| `Shift` | 押しながら打つと**大文字**や記号 |
| `Tab` | 次の入力欄へ移動 |
| 矢印キー `← ↑ ↓ →` | カーソルを動かす |

> 💡 **プログラミングは半角の英数字・記号で書きます。** 記号（`{ } ( ) [ ] ; : " ' / \`）の場所は、最初は探しながらでOK。打つうちに指が覚えます。

---

## STEP 3 ─ 日本語と英語を切り替える（IME）

文章は日本語、コードは英語（半角）で打ちます。切り替えを覚えましょう。

| 環境 | 切り替え方 |
| --- | --- |
| Windows | `半角/全角` キー（左上）。または `Alt + 半角/全角` |
| Mac | `英数` キー（半角英語）／`かな` キー（日本語）。スペース左右にあります |

> ⚠️ **超重要**：プログラミングでは **半角** の英数字・記号を使います。**全角の記号（例：`（）` `；`）や全角スペースが混ざるとエラー**になります。見た目が似ていて気づきにくいので、コードを打つときは必ず「英数（半角）」に切り替えてください（この対策はレッスン 0-5 で設定します）。

---

## STEP 4 ─ ファイルとフォルダ

プログラムは「ファイル」を作って書きます。ファイルは「フォルダ」の中に整理します。

- **ファイル**：1つの書類。名前と「拡張子」（`.txt` `.html` など、種類を表す末尾）を持つ
- **フォルダ**：ファイルをまとめる入れ物。中にフォルダを入れることもできる

### 拡張子を表示する（最初にやっておくと安心）

初期設定では拡張子が隠れていることがあります。表示しておくと「`.html` のつもりが `.txt` だった」という事故を防げます。

- **Windows**：エクスプローラー →「表示」→「ファイル名拡張子」にチェック
- **Mac**：Finder → 設定 → 詳細 →「すべてのファイル名拡張子を表示」にチェック

> 🖐 **やってみよう**：デスクトップに新しいフォルダを1つ作り、`renshu`（練習）と名前を付けてみましょう。作り方は、何もない所を**右クリック → 新規作成 → フォルダー**（Mac は右クリック →「新規フォルダ」）。

---

## STEP 5 ─ ダウンロードとインストール

この先、無料のソフトを入れます。基本の流れはどれも同じです。

1. 配布元の**公式サイト**を開く
2. 「ダウンロード」ボタンを押す
3. ダウンロードされたファイル（多くは「ダウンロード」フォルダに入る）を**ダブルクリック**
4. 画面の指示に従って進める

> ⚠️ **偽物のダウンロードボタンに注意。** 広告に大きな「ダウンロード」ボタンが出ることがあります。**必ず公式サイトのボタン**を押してください。どれが公式か不安なときは、あとで学ぶ「AIに聞く」で確認できます。

---

## STEP 6 ─ ブラウザを使いこなす

ブラウザ（Chrome など）は、Webを見る道具であり、これから作るものを確認する道具です。

| 操作 | 方法 |
| --- | --- |
| ページを開く | 上のアドレス欄にURLを入れて `Enter` |
| タブ | 上の「＋」で新しいページを別枠で開く |
| 戻る／進む | 左上の `←` `→` |
| 再読み込み | `F5`、または `Ctrl + R`（Mac は `Cmd + R`） |
| ブックマーク | よく使うページを保存（星マーク） |

---

## STEP 7 ─ これだけは覚えたいショートカット

キーを組み合わせると作業が速くなります。**まずこの5つ**だけで十分です。

| やりたいこと | Windows | Mac |
| --- | --- | --- |
| コピー | `Ctrl + C` | `Cmd + C` |
| 貼り付け | `Ctrl + V` | `Cmd + V` |
| 元に戻す | `Ctrl + Z` | `Cmd + Z` |
| 保存 | `Ctrl + S` | `Cmd + S` |
| すべて選択 | `Ctrl + A` | `Cmd + A` |

> 🖐 **やってみよう**：メモ帳（Windows）／テキストエディット（Mac）を開いて、何か文字を打ち、`Ctrl/Cmd + A` → `Ctrl/Cmd + C` → 改行して `Ctrl/Cmd + V`。コピー＆貼り付けができたら成功です。

---

## STEP 8 ─ スクリーンショット（質問のときに役立つ）

困ったとき、画面を画像で保存できると、AIや人に状況を伝えやすくなります。

- **Windows**：`Windows + Shift + S` → 範囲を選ぶ → 画像がコピーされる
- **Mac**：`Shift + Cmd + 4` → 範囲を選ぶ → デスクトップに画像が保存される
