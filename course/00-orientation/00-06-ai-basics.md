# 0-6 AIを開発の相棒にする — 基本編

> 🎯 **このレッスンのゴール**
> - AIに「効く質問」と「効かない質問」の違いがわかる
> - 学習に使えるAIの4つの役割を使い分けられる
> - 自分専用のプロンプトテンプレートを手に入れる

所要 60分 / 難度 🟢

---

## 大前提：AIを使うと学習は速くなる。ただし条件がある

まず、はっきりさせておきます。

**AIを使うこと自体は、まったく悪いことではありません。** 現役のエンジニアは全員使っています。使わないほうが不利です。

ただし、**使い方を間違えると、学習効果はゼロどころかマイナスになります。**

| ダメな使い方 | 何が起きるか |
| --- | --- |
| 「ToDoアプリ作って」→ コピペ → 動いた → 次へ | 何も残らない。3日後に同じものが作れない |
| エラーが出たら即「これ直して」 | エラーが読めるようにならない。AIがいないと詰む |
| 出てきたコードを理解せず本番投入 | セキュリティホールを埋め込む。第3部・第4部で実例を見ます |

| 良い使い方 | 何が起きるか |
| --- | --- |
| 自分で書く → AIに説明させる → 差分を確認 | 理解の穴が可視化される |
| エラーを自分で15分読む → AIに「原因の候補を3つ」と聞く | 読み方が身につく |
| 「なぜこの書き方なのか」を問い詰める | 設計判断ができるようになる |

**境界線は「AIに考えさせているか、自分が考えているか」です。**

> 💡 この教材では、AI使用を禁止しません。むしろ推奨します。ただし**「④ 自分で変える」ステップは、必ず自力でやってください。** ここだけは AI に渡さない、と決めてください。

---

## AIの4つの役割

学習中のAIは、次の4つの役割で使い分けます。

```
①【家庭教師】 わからない概念を説明させる
②【デバッガー】 エラーの原因候補を挙げさせる
③【レビュアー】 自分のコードの問題点を指摘させる
④【出題者】 演習問題を作らせる・採点させる
```

**「⑤ 代筆者（コードを書かせる）」は、当面は封印してください。** 第2部の後半（レッスン2-12）で解禁します。それまでは、コードは自分で書きます。

---

## ① 家庭教師として使う

### ダメな質問

```text
Flexboxについて教えて
```

→ 教科書的な一般論が返ってきます。すでに読んだ内容の繰り返しで、時間の無駄です。

### 効く質問

```text
私はWeb開発の初学者で、CSSのFlexboxを学んでいます。

以下のコードで、要素が横並びになりません。なぜですか？

（コードを貼る）

回答のとき、次の3点をお願いします。
1. 中学生でもわかる比喩を使って説明する
2. 専門用語を使う場合は、必ずその場で意味を添える
3. 最後に、私が理解できたか確認するための質問を1つ出す
```

**効く質問の4要素**

| 要素 | 例 |
| --- | --- |
| **前提** | 「私は初学者で」「PHPは学習3日目で」 |
| **具体物** | コード・エラー文・スクショの説明を貼る |
| **知りたいこと** | 「なぜ動かないか」「2つの違いは何か」 |
| **回答の形式指定** | 「比喩で」「3つ挙げて」「表にして」「最後にクイズを1問」 |

### 最強の質問：「なぜ」を3回

```text
CSSで display: flex を指定すると横並びになる、と学びました。

なぜ display の値を変えると並び方が変わるのですか？
そもそも display とは何を決めているプロパティなのですか？
block と inline と flex は、それぞれ何が違うのですか？

初学者向けに、図やイメージが浮かぶ説明でお願いします。
```

**丸暗記を防ぐ最も有効な手段は、「なぜ」を掘ることです。**

## ② デバッガーとして使う

**ルール：自分で15分読んでから聞く。**

### テンプレート（そのまま使えます）

```text
【状況】
PHPの学習中に、以下のエラーが出て解決できません。

【環境】
- Windows 11 / XAMPP 8.2
- ブラウザ: Chrome

【エラーメッセージ】
（コピペで丸ごと貼る。省略しない）

【該当コード】
（エラーが出ているファイル全体を貼る）

【自分で試したこと】
- ○○を確認したが問題なさそう
- ××を変えてみたが変化なし

【お願い】
1. 原因として考えられるものを、可能性の高い順に3つ挙げてください
2. それぞれについて、原因かどうかを確認する方法を教えてください
3. すぐに答えを教えるのではなく、まず私が自分で確認できる手順を示してください
```

> 💡 最後の一文が効きます。「答えを教えないで」と指示すると、AIは診断の手順を教えてくれます。**その手順こそが、あなたが身につけるべきスキルです。**

### ⚠️ やってはいけないこと

- **エラーメッセージを要約して伝える** → 「なんかエラーが出ました」では診断できません。**丸ごとコピペ**が鉄則です
- **コードの一部だけ貼る** → 原因は貼っていない部分にあることが多いです
- **返ってきたコードをそのまま全置換** → 何が原因だったのかがわからないまま。**差分を必ず確認**します

## ③ レビュアーとして使う

自分でコードを書いたら、必ずレビューさせてください。**これが最もコスパの高い使い方です。**

```text
以下は、私が書いたPHPのコードです。学習3週間目の初学者が書いたものです。

（コードを貼る）

次の観点でレビューしてください。

1. 動作上のバグがあるか
2. セキュリティ上の問題があるか（あれば、なぜ危険かを具体的に）
3. 読みやすさ・命名の改善点
4. もっと簡潔に書ける箇所

ただし、修正後のコードは提示しないでください。
「どこを・なぜ直すべきか」だけを指摘してください。
私が自分で直します。
```

> **「修正コードは出さないで」** — この一文が、学習効果を守ります。
> 直し方を自分で考える時間が、実力になります。

## ④ 出題者として使う

インプットだけでは定着しません。AIに問題を作らせましょう。

```text
私はJavaScriptの配列メソッド（map / filter / reduce）を学びました。

理解度を確認したいので、以下の条件で練習問題を5問作ってください。
- 難易度は易しいものから順に
- 実務でありそうな題材（商品リスト、ユーザー一覧など）
- 各問題に「入力データ」と「期待する出力」を明記
- 解答はまだ書かないでください

私が解答を送ったら、1問ずつ採点し、間違っていた場合は
「なぜ間違えたか」の思考のズレを指摘してください。
```

## 自分専用のシステムプロンプトを作る

毎回「私は初学者で…」と書くのは面倒です。ChatGPT なら「カスタム指示」、Claude なら「プロジェクトのカスタム指示」に、以下を登録しておきましょう。

```text
私はWeb開発を学習中の初学者です。
HTML / CSS / JavaScript / PHP / MySQL / Laravel を学んでいます。

回答するときは、次のルールを守ってください。

1. 専門用語を使うときは、必ず初出時に一言で意味を添える
2. コードを提示するときは、各行またはブロックにコメントで説明を入れる
3. 私がエラーの原因を尋ねた場合、いきなり修正コードを出さず、
   まず原因の候補を可能性の高い順に3つ挙げ、確認手順を示す
4. 私が書いたコードのレビューを求めた場合、修正コードは書かず、
   指摘だけをしてください
5. 断定できない内容は「確実ではないが」と明示してください
6. 回答の最後に、私が次に確認すべきことを1つ提案してください
```

> ✍️ **手を動かす**：いま使っているAIツールに、この指示を登録してください。以降のレッスンが格段に楽になります。

## ⚠️ つまずきポイント：AIが平気で嘘をつく

AIは**それらしい嘘**をつきます。これを**ハルシネーション**と呼びます。

初学者が特に引っかかるパターン：

| パターン | 具体例 |
| --- | --- |
| **存在しない関数を作る** | PHPに `str_reverse()` はありません（正しくは `strrev()`） |
| **古い書き方を出す** | 非推奨・削除済みの関数（`mysql_query()` など）を提示する |
| **バージョン違い** | Laravel 8 の書き方を、11 の質問に対して答える |
| **もっともらしい嘘の理由付け** | 動かない理由を、それらしく間違って説明する |

**対策は次のレッスン（0-7）で本格的に扱います。** ここでは、まず「AIは嘘をつく」と頭に入れてください。

> 💡 **AIが嘘をついても、あなたの責任です。**
> 実務では「AIがそう言ったので」は通用しません。だからこそ、検証の技術が価値になります。

## 🔧 やってみよう

1. 使っている AI ツールに、上記のシステムプロンプトを登録する
2. 次のプロンプトを実際に投げて、返ってきた答えを `learning-log.md` に貼る

```text
Webサイトが表示される仕組みについて学びました。
理解度チェックのため、初学者向けのクイズを5問出してください。
まだ答えは書かないでください。私が回答したら採点してください。
```

3. 5問に自分の言葉で答えて、採点してもらう
4. **間違えた問題があれば、レッスン0-3を読み直す**
