# 0-4 開発環境をつくる（Windows / Mac）

> ◎ **このレッスンのゴール**
> - Chrome / VS Code / XAMPP(MAMP) を導入し、PHP と MySQL が動く状態を作る
> - 「ローカル環境」がどこにあるのか、フォルダの場所を体で覚える

所要 90分 / 難度 🟡

---

## 最初に読んでください

**このレッスンは、この教材で最も脱落者が出る場所です。** そして、脱落する理由はほぼ1つ。

> 「手順通りにやったのに、書いてある画面が出ない」

環境構築は、OSのバージョン・既存のソフト・セキュリティ設定によって画面が変わります。**書いてある通りにならないのが普通**だと思ってください。

このレッスンでは、うまくいかなかったときの分岐を全部書きます。焦らず、1つずつ確認していきましょう。

> ⚠️ **時間がかかっても、それはあなたのせいではありません**
> 環境構築に3時間かかった、という報告は珍しくありません。現役エンジニアも新しいPCのセットアップには半日使います。ここで時間を使うのは「遅れ」ではなく「通過儀礼」です。

## STEP 1: Google Chrome

すでに入っている場合は STEP 2 へ。

1. https://www.google.com/chrome/ を開く
2. 「Chromeをダウンロード」をクリック
3. ダウンロードされたファイルを実行し、指示に従う

> **なぜ Chrome か**：開発者ツールの情報量が最も多く、学習中に検索して出てくる記事もほぼ Chrome 前提だからです。普段使いのブラウザは何でも構いませんが、**動作確認は Chrome で**行ってください。

---

## STEP 2: Visual Studio Code

1. https://code.visualstudio.com/ を開く
2. 自分のOSのボタンをクリックしてダウンロード
3. インストーラを実行

### Windows の場合の注意

インストール中の「追加タスクの選択」画面で、**次の2つに必ずチェック**を入れてください。

- [x] 「エクスプローラーのファイル コンテキスト メニューに [Codeで開く] アクションを追加する」
- [x] 「PATH への追加」

> ⚠️ チェックを入れ忘れた場合
> 一度アンインストールして入れ直せば選び直せます。ただし必須ではないので、先に進んでも構いません。

### Mac の場合の注意

ダウンロードした `.zip` を解凍すると `Visual Studio Code.app` が出てきます。**これを「アプリケーション」フォルダにドラッグ**してください。ダウンロードフォルダのまま使うと、後で消えて混乱します。

### 動作確認

VS Code を起動して、こういう画面が出れば成功です。

```
┌─────────────────────────────────────┐
│  ファイル 編集 選択 表示 ...          │
├──┬──────────────────────────────────┤
│📄│                                   │
│🔍│      Visual Studio Code           │
│🌿│      編集の開始                    │
│▶ │      ・新しいファイル              │
│⬛│      ・ファイルを開く              │
└──┴──────────────────────────────────┘
```

## STEP 3: PHP と MySQL の環境（XAMPP / MAMP）

PHP を動かすには、あなたのPCの中に**小さなWebサーバー**を立てる必要があります。それをまとめて用意してくれるのが XAMPP（ザンプ）と MAMP（マンプ）です。

- **Windows → XAMPP**
- **Mac → MAMP**（XAMPPでも可ですが、MAMPのほうがトラブルが少ないです）

---

### 3-A. Windows：XAMPP を入れる

#### インストール

1. https://www.apachefriends.org/jp/index.html を開く
2. 「XAMPP for Windows」をクリックしてダウンロード
   - **PHP 8.2 系**を選んでください（Laravel が動くバージョンです）
3. ダウンロードした `.exe` を**右クリック → 管理者として実行**

> ⚠️ **「User Account Control (UAC) warning」が出た場合**
> 「OK」で進んで構いません。ただし、**インストール先は `C:\xampp` のまま**にしてください。
> `C:\Program Files` 配下に入れると権限エラーで詰みます。

4. コンポーネント選択画面では、**すべてチェックが入ったまま**「Next」
5. インストール先は `C:\xampp` のまま「Next」
6. 「Bitnami for XAMPP」のチェックは**外して**「Next」（不要です）
7. インストール完了

#### 起動する

1. スタートメニューから「XAMPP Control Panel」を起動
2. **Apache** の「Start」をクリック
3. **MySQL** の「Start」をクリック
4. どちらも背景が**緑色**になれば成功

```
Modules
Service  Module      PID(s)   Port(s)   Actions
  ☐      Apache      1234     80, 443   [Stop] [Admin] [Config] [Logs]  ← 緑
  ☐      MySQL       5678     3306      [Stop] [Admin] [Config] [Logs]  ← 緑
```

#### ⚠️ Apache が起動しない場合（超頻出）

赤い文字で `Port 80 in use by ...` と出たら、**他のソフトがポート80を使っています**。

**原因の9割はこの3つです。**

| 犯人 | 対処 |
| --- | --- |
| Skype | Skype の設定 → 詳細 → 接続 → 「ポート80と443を使用」のチェックを外す |
| IIS（Windows付属） | コントロールパネル → プログラム → Windowsの機能 → 「インターネットインフォメーションサービス」のチェックを外す |
| VMware / Hyper-V | 一時的にサービスを停止する |

**どれでもない場合は、XAMPP側のポートを変えるのが早いです。**

1. Control Panel の Apache 行の「Config」→「Apache (httpd.conf)」
2. `Listen 80` を `Listen 8080` に変更
3. `ServerName localhost:80` を `ServerName localhost:8080` に変更
4. 保存して Apache を Start
5. 以降、ブラウザでは `http://localhost:8080/` でアクセスします

> 💡 ポート番号を変えたら、この教材で `http://localhost/` と書いてある箇所はすべて `http://localhost:8080/` に読み替えてください。**メモしておきましょう。**

#### ⚠️ MySQL が起動しない場合

`Port 3306 in use` と出たら、以前入れた MySQL が残っています。

1. `Win + R` → `services.msc` を実行
2. 一覧から `MySQL` または `MySQL80` を探す
3. 右クリック → 停止 → プロパティ → スタートアップの種類を「手動」に

---

### 3-B. Mac：MAMP を入れる

#### インストール

1. https://www.mamp.info/en/downloads/ を開く
2. 「MAMP & MAMP PRO」の macOS 版をダウンロード
3. `.pkg` を実行してインストール（MAMP PRO も一緒に入りますが、**無料の MAMP のほうだけ使います**）

> ⚠️ **「開発元が未確認のため開けません」と出たら**
> システム設定 → プライバシーとセキュリティ → 下のほうに「"MAMP"はブロックされました」→「このまま開く」

#### 起動する

1. アプリケーション → MAMP → **MAMP.app**（PROではないほう）を起動
2. 「Start Servers」をクリック
3. 右上の2つのランプが**緑**になれば成功
4. 自動でブラウザが開きます（開かなければ `http://localhost:8888/MAMP/`）

> 💡 **MAMP のポートは初期状態で 8888 です。**
> この教材で `http://localhost/` とある箇所は `http://localhost:8888/` に読み替えてください。
> ポート80に変えることもできますが（Preferences → Ports → 「Set Web & MySQL ports to 80 & 3306」）、その場合は起動のたびに管理者パスワードを求められます。**8888のままで進めるのがおすすめです。**

#### PHP のバージョンを確認・変更する

1. MAMP → Preferences → PHP タブ
2. Standard Version を **8.x** に設定

## STEP 4: 動作確認 — 最初のPHPファイル

ここまで来たら、実際に PHP を動かしてみましょう。

### ドキュメントルートを開く

**あなたが作ったファイルは、決まったフォルダに置かないと表示されません。** その場所を「ドキュメントルート」と呼びます。

| 環境 | ドキュメントルート |
| --- | --- |
| Windows / XAMPP | `C:\xampp\htdocs` |
| Mac / MAMP | `/Applications/MAMP/htdocs` |

> ⚠️ **ここが最重要ポイントです**
> デスクトップに作ったPHPファイルは、**絶対に動きません**。必ず `htdocs` の中に置いてください。
> 「PHPが実行されずコードがそのまま表示される」というトラブルの原因は、ほぼこれです。

### ファイルを作る

1. `htdocs` の中に `lesson` という名前のフォルダを作る
2. VS Code で「File → Open Folder」から、いま作った `lesson` フォルダを開く
3. 新規ファイル `test.php` を作り、以下を入力（**手で打ってください**）

```php
<?php
phpinfo();
```

4. 保存（`Ctrl + S` / `Cmd + S`）

### ブラウザで開く

| 環境 | URL |
| --- | --- |
| XAMPP（ポート80） | `http://localhost/lesson/test.php` |
| XAMPP（ポート8080に変更した場合） | `http://localhost:8080/lesson/test.php` |
| MAMP | `http://localhost:8888/lesson/test.php` |

**紫色のヘッダーがついた、PHPの設定情報がずらっと並んだページ**が出れば成功です 🎉

```
┌───────────────────────────────────────┐
│  PHP Version 8.2.12                   │  ← これが出れば成功
├───────────────────────────────────────┤
│  System        Windows NT ...          │
│  Build Date    Nov  1 2023             │
│  ...                                   │
└───────────────────────────────────────┘
```

### ⚠️ うまくいかないとき

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| `<?php phpinfo(); ?>` という**文字がそのまま表示される** | ファイルが htdocs の外にある / 拡張子が `.php` でない | ファイルの場所と拡張子を確認。`test.php.txt` になっていないか要注意 |
| **404 Not Found** | URLのパスが間違っている | フォルダ名・ファイル名のスペルを確認。大文字小文字も区別されます |
| **真っ白なページ** | PHPの文法エラー | `<?php` のスペルを確認。全角スペースが混じっていないか確認 |
| **このサイトにアクセスできません** | Apache が起動していない | Control Panel / MAMP で起動状態を確認 |
| **403 Forbidden** | フォルダのアクセス権限 | フォルダ名に日本語やスペースが入っていないか確認 |

> ⚠️ **全角スペース事件**
> 日本語環境で最も多いエラー原因です。コードの中に全角スペース（`　`）が1つでも入ると動きません。見た目では区別がつきません。
> 対策 → レッスン0-5で「全角スペースを可視化する設定」を行います。

> 🆘 **ここで詰まったら**（上の表を試しても紫のページが出ない）
> - **切り分け**：`http://localhost/`（XAMPPなら）だけを開いてみる。XAMPPのダッシュボードが出れば**サーバーは動いている**＝ファイルの場所か名前の問題。出なければ**Apacheが起動していない**（この後のAI相談へ）
> - **直らなければ、下の「🤖 AIに聞いてみよう」のプロンプトに、エラー文（または「何が起きたか」）をそのまま貼って相談してください。** 環境構築のトラブルはAIが最も得意な領域です。焦らず1つずつ確認しましょう。

## STEP 5: MySQL の動作確認

1. ブラウザで phpMyAdmin を開く
   - XAMPP: `http://localhost/phpmyadmin/`
   - MAMP: `http://localhost:8888/phpMyAdmin/`（MAMPのスタートページからもリンクがあります）
2. 左側にデータベース一覧が表示されれば成功

> ⚠️ MAMP で phpMyAdmin が開けない場合、MAMPのスタートページ（`http://localhost:8888/MAMP/`）から「Tools → phpMyAdmin」で開けます。

第4部までは触りませんが、**開けることだけ確認**しておいてください。

## 🤖 AIに聞いてみよう

環境構築のトラブルは、AI がとても得意な領域です。**エラー文をそのまま貼る**のがコツです。

```text
Windows 11 で XAMPP をインストールしました。
XAMPP Control Panel で Apache を Start しようとすると、
以下のエラーが出て起動しません。

（ここにエラーログを丸ごと貼る）

考えられる原因を、可能性の高い順に3つ挙げてください。
それぞれについて、原因を特定するための確認手順と、対処方法を
初学者にもわかるように具体的に教えてください。
```

> 💡 **「可能性の高い順に3つ」と指定する**のがポイントです。
> ただ「教えて」と聞くと、AIは1つの原因を断定的に答えます。それが外れていると、初学者は行き詰まります。複数出させて、上から試すのが正解ルートです。

## 🔧 やってみよう

1. `htdocs/lesson` の中に `hello.php` を作り、次を書いて表示させてください。

```php
<?php
echo "環境構築おわった！";
```

2. わざと壊してみましょう。`echo` を `eco` に変えて保存し、ブラウザを更新してください。
   - 何が起きましたか？ 画面に出たメッセージをメモしてください
   - このメッセージが「エラーの読み方」を学ぶ最初の教材です（レッスン3-1で詳しく扱います）
3. `eco` を `echo` に戻して、直ることを確認してください。

> **壊して直す経験は、動くコードを10個書くより価値があります。** これからも積極的に壊してください。
