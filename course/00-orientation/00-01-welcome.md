# 0-1 ようこそ / この教材の使い方

> 🎯 **このレッスンのゴール**
> - この教材がどんな順番で進むのかを把握する
> - 「わからない」が来たときの対処ルートを、先に決めておく

所要 20分 / 難度 🟢

---

## はじめに：あなたは何も悪くない

もしあなたが過去にプログラミング学習で挫折したことがあるなら、それはほぼ確実に**教材の設計の問題**です。

初学者がつまずく瞬間は、驚くほど決まっています。

- 環境構築の途中で、書いてある通りにやったのにエラーが出る
- 英語のエラーメッセージが出て、何を直せばいいか見当もつかない
- コードは動いたが、「なぜ動いたか」がわからないまま次に進んでしまう
- 質問できる相手がいない（あるいは、何を質問すればいいかもわからない）

この教材は、この4つを潰すことだけを考えて作られています。

## この教材の3つの約束

### 約束1：手順は必ず分岐まで書く

「〇〇をインストールしてください」で終わらせません。**うまくいかなかったときにどうするか**まで書きます。

> ⚠️ **つまずきポイント**
> こういう囲みが出てきたら、そこは実際に多くの人が転ぶ場所です。まだ転んでいなくても、必ず読んでください。「あ、これ書いてあったやつだ」と思えることが、後で効きます。

### 約束2：AIの使い方を、技術として教える

いまや、現役のエンジニアで AI を使っていない人はほとんどいません。にもかかわらず、多くの教材は AI を「おまけ」扱いします。

この教材では、AI活用を**独立した学習項目**として扱います。

- 何を聞けば、まともな答えが返ってくるのか（プロンプトの型）
- 返ってきたコードが正しいかを、初学者がどう確かめるのか
- どこまで任せてよくて、どこからは自分で理解しないと詰むのか

> 🤖 **AIに聞いてみよう**
> こういう囲みには、そのままコピペして使えるプロンプトが入っています。実際に AI に投げながら進めてください。

### 約束3：必ず「動くもの」が手元に残る

各部の最後には総合演習があります。修了時点で、あなたの GitHub には次のものが並びます。

1. 架空カフェのランディングページ（HTML / CSS）
2. ToDoアプリ（JavaScript）
3. 掲示板アプリ（PHP + MySQL）
4. フリマアプリ（Laravel・認証つき）
5. オリジナル制作物

## 進め方のルール

### ルール1：写経して終わりにしない

各レッスンは次の4ステップです。**3番目を飛ばさないでください。**

| ステップ | やること | 目的 |
| --- | --- | --- |
| ① 読む | 解説を読んで、やろうとしていることを掴む | 地図を持つ |
| ② 打つ | コードを**自分で打つ**（コピペしない） | 手に覚えさせる |
| ③ 説明させる | AIに「このコードを1行ずつ説明して」と投げる | 理解の穴を見つける |
| ④ 変える | 演習で、自分の意図でコードを変える | 応用できる状態にする |

コピペは 5 秒で終わりますが、手打ちは 2 分かかります。その差の 1 分 55 秒が、タイポの直し方とエラーの読み方を教えてくれます。**この教材では、コードは手で打ってください。**

### ルール2：15分ルール

詰まったら、**15分だけ**自力で粘る。15分を超えたら次の順で助けを借ります。

```
1. そのレッスンの「⚠️ つまずきポイント」を読み直す
   ↓ 解決しない
2. 巻末の「エラー図鑑」でエラーメッセージを検索する
   ↓ 解決しない
3. AIに聞く（聞き方はレッスン 0-6 で学びます）
   ↓ 解決しない
4. エラーメッセージをそのまま Google 検索する
   ↓ 解決しない
5. いったん飛ばして先に進み、翌日もう一度見る
```

**5番は「逃げ」ではありません。** 一晩寝かせると解決することは、プロでも日常的にあります。

> 🆘 **ここで詰まったら**（15分の壁を越えられないとき）
> - **まず確認**：エラーが出ているなら、その全文をコピーしたか（一部だけだと原因が絞れません）
> - **AIにこう聞く**（詳しい聞き方は 0-6 で学びますが、まずはこれで十分）：
>   「プログラミング初心者です。○○をしようとして、△△というエラー（または状態）になりました。原因の候補と、私が自分で確認する手順を、やさしく教えてください。いきなり答えのコードは出さないでください」
> - この教材では、各レッスンの手を止めやすい箇所に **「🆘 ここで詰まったら」** を置いています。困ったら、まず一番近いこの印を探してください。

### ルール3：完璧に理解してから進もうとしない

理解度が 7 割でも進んでください。プログラミングの知識は、後の章で何度も再登場します。1回目で 7 割、2回目で 9 割、3回目で腹落ち、が普通のペースです。

「完全に理解してから次へ」は、最も多い挫折パターンです。

## 学習環境について

必要なものは以下だけです。第0部のレッスン 0-4 で全部そろえます。

| 必要なもの | 備考 |
| --- | --- |
| パソコン | Windows 10以降 / macOS 12以降。メモリ8GB以上推奨 |
| インターネット環境 | — |
| Google Chrome | 開発者ツールを使います |
| Visual Studio Code | 無料のエディタ |
| XAMPP または MAMP | PHP / MySQL 実行環境。無料 |
| AI チャットツール | ChatGPT / Claude / Gemini のいずれか。無料プランで可 |

すべて無料です。有料ツールは必須ではありません。
