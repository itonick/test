# 用語集

`Ctrl + F` で検索してください。

## Web の基礎

| 用語 | 読み | ざっくり言うと |
| --- | --- | --- |
| クライアント | — | サービスを使う側。ふつうはブラウザのこと |
| サーバー | — | サービスを提供する側のコンピュータ |
| リクエスト | — | ブラウザからサーバーへの「これください」 |
| レスポンス | — | サーバーからブラウザへの「はいどうぞ」 |
| HTTP / HTTPS | エイチティーティーピー | ブラウザとサーバーの会話のルール。SはSecure（暗号化） |
| ステータスコード | — | レスポンスに付く3桁の数字。200=成功、404=なし、500=サーバーエラー |
| DNS | ディーエヌエス | ドメイン名（example.com）をIPアドレスに変換する電話帳 |
| IPアドレス | — | インターネット上の住所。`192.168.1.1` のような数字 |
| ドメイン | — | `example.com` のような、人間が読める住所 |
| ポート番号 | — | 1台のサーバーの中の「部屋番号」。Webは通常80/443 |
| フロントエンド | — | ブラウザの中で動く部分（HTML/CSS/JS） |
| バックエンド | — | サーバーの中で動く部分（PHP/DB） |
| ローカル環境 | — | 自分のPCの中に作った練習用サーバー |
| 本番環境 | — | 実際に世界に公開されているサーバー |
| デプロイ | — | 作ったものを本番環境に配置して公開すること |
| API | エーピーアイ | プログラム同士がデータをやり取りするための窓口 |
| CDN | シーディーエヌ | ファイルを世界中に分散配置して高速配信する仕組み |

## HTML / CSS

| 用語 | ざっくり言うと |
| --- | --- |
| タグ | `<p>` のような、HTMLの部品を表す記号 |
| 要素 | 開始タグ〜終了タグまでの一かたまり |
| 属性 | タグに付ける追加情報（`class="box"` の部分） |
| セマンティック | 「意味のある」。`<div>` でなく `<header>` を使うなど |
| セレクタ | CSSで「どの要素に」を指定する部分（`.box` など） |
| プロパティ | CSSで「何を」変えるか（`color` など） |
| ボックスモデル | 要素が「内容＋padding＋border＋margin」でできているという考え方 |
| padding | 枠の**内側**の余白 |
| margin | 枠の**外側**の余白 |
| Flexbox | 要素を1方向（横または縦）に並べるレイアウト手法 |
| Grid | 要素を2次元（行と列）に並べるレイアウト手法 |
| レスポンシブ | 画面幅に応じてレイアウトを変える設計 |
| メディアクエリ | 「画面幅が〇px以下なら」という条件分岐（CSS） |
| ビューポート | ブラウザの表示領域 |
| 詳細度 | CSSの優先順位。ID > クラス > 要素 |
| 疑似クラス | `:hover` など、状態に応じたスタイル指定 |
| Emmet | 略記からHTMLを展開するエディタ機能（`ul>li*3` など） |

## プログラミング共通

| 用語 | ざっくり言うと |
| --- | --- |
| 変数 | 値を入れておく名前付きの箱 |
| 定数 | 一度入れたら変えられない箱 |
| 型 | 値の種類（文字列、数値、真偽値など） |
| 文字列 | 文字のならび。`"hello"` |
| 真偽値 / boolean | `true` か `false` のどちらか |
| 配列 | 複数の値を順番に並べて入れる箱 |
| 連想配列 / オブジェクト | 名前をキーにして値を入れる箱 |
| 関数 | 処理をひとまとめにして名前を付けたもの |
| 引数 | 関数に渡す値 |
| 戻り値 | 関数が返す値 |
| スコープ | 変数が見える範囲 |
| 条件分岐 | `if` などで処理を分けること |
| ループ / 繰り返し | `for` `while` などで同じ処理を繰り返すこと |
| コメント | プログラムとして実行されないメモ |
| インデント | 行頭の字下げ。読みやすさのため |
| デバッグ | バグ（不具合）を見つけて直す作業 |
| リファクタリング | 動作を変えずにコードを整理すること |
| ライブラリ | よく使う機能をまとめた部品集 |
| フレームワーク | アプリの土台となる骨組み |
| 例外 / エラー | 想定外の事態。処理が止まる |
| 同期 / 非同期 | 順番に待つ / 待たずに次へ進む |

## JavaScript

| 用語 | ざっくり言うと |
| --- | --- |
| DOM | ドム。HTMLをJavaScriptから操作するための木構造の表現 |
| イベント | クリック、入力など、ユーザーの操作 |
| イベントリスナー | 「クリックされたらこれをやる」という登録 |
| コールバック関数 | 他の関数に渡して、あとで実行してもらう関数 |
| アロー関数 | `() => {}` という短い関数の書き方 |
| Promise | 「あとで結果が返る」ことを表すオブジェクト |
| async / await | 非同期処理を、同期のように読みやすく書く記法 |
| fetch | サーバーからデータを取ってくる関数 |
| JSON | ジェイソン。データをやり取りするための文字列形式 |
| localStorage | ブラウザにデータを保存する仕組み |
| コンソール | 開発者ツールの、ログとエラーが出る場所 |
| null / undefined | 「空」/「未定義」。どちらも値がない状態 |
| NaN | Not a Number。数値計算が失敗した結果 |

## PHP

| 用語 | ざっくり言うと |
| --- | --- |
| `echo` | 画面に出力する命令 |
| `$_GET` / `$_POST` | URLやフォームから送られてきたデータが入る箱 |
| スーパーグローバル | どこからでも使える特別な変数（`$_GET` など） |
| セッション | サーバー側でユーザーごとの情報を保持する仕組み |
| クッキー | ブラウザ側に保存される小さなデータ |
| エスケープ | 危険な文字を無害な表記に変換すること |
| `htmlspecialchars()` | HTMLの特殊文字をエスケープする関数。XSS対策の基本 |
| バリデーション | 入力値が正しいかチェックすること |
| サニタイズ | 入力値から危険な部分を除去すること |
| `require` / `include` | 他のファイルを読み込む。requireは失敗すると停止 |
| Composer | PHPのライブラリ管理ツール |
| PSR | PHPのコーディング規約 |
| 名前空間 | クラス名の衝突を避けるための「住所」 |

## データベース / SQL

| 用語 | ざっくり言うと |
| --- | --- |
| RDB | 表形式でデータを管理するデータベース |
| テーブル | 表。Excelのシートのようなもの |
| レコード / 行 | 1件分のデータ |
| カラム / 列 | 項目（名前、メールアドレスなど） |
| 主キー / PRIMARY KEY | 各行を一意に識別する列。通常は `id` |
| 外部キー / FOREIGN KEY | 別テーブルの主キーを指す列 |
| インデックス | 検索を速くするための索引 |
| SELECT / INSERT / UPDATE / DELETE | 取得 / 追加 / 更新 / 削除 |
| WHERE | 条件を指定する句 |
| JOIN | 複数テーブルをつなげて取得する |
| 正規化 | データの重複をなくすテーブル設計の手法 |
| トランザクション | 複数の処理を「全部成功か、全部取り消し」にまとめる |
| PDO | PHPからDBを操作する標準の仕組み |
| プレースホルダ | SQLに値を安全に埋め込む仕組み。`?` や `:name` |
| SQLインジェクション | 悪意あるSQLを注入される攻撃 |

## Laravel

| 用語 | ざっくり言うと |
| --- | --- |
| MVC | Model（データ）/ View（見た目）/ Controller（制御）に分ける設計 |
| ルーティング | URLと処理を対応づける仕組み |
| コントローラ | リクエストを受けて、処理を振り分ける係 |
| モデル | データベースのテーブルに対応するクラス |
| ビュー | 画面のテンプレート |
| Blade | ブレード。Laravelのテンプレートエンジン |
| Eloquent | エロクアント。LaravelのORM。SQLを書かずにDB操作できる |
| ORM | オブジェクトとテーブルを対応づける仕組み |
| マイグレーション | テーブル定義をコードで管理する仕組み |
| シーダー | テスト用のデータを流し込む仕組み |
| Artisan | アルチザン。Laravelのコマンドラインツール |
| ミドルウェア | リクエストの前後に挟む共通処理（ログイン確認など） |
| バリデーション | 入力チェック。Laravelでは強力な機能が用意されている |
| CSRF | シーサーフ。なりすまし送信を防ぐ仕組み |
| `.env` | 環境ごとの設定を書くファイル。**Git管理しない** |
| リレーション | テーブル間の関係（1対多など）をコードで表現したもの |
| N+1問題 | ループの中でクエリが大量に発行される性能問題 |

## Git / 開発

| 用語 | ざっくり言うと |
